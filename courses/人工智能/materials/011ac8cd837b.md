## 分节 1

基于 HyCF-TFM 框架的心衰风险预测：多模态纵向融合与合成数据工程的实验设计深度报告
1. 绪论：心衰管理中的计算范式重构与 Agentic AI 的兴起
心力衰竭（Heart Failure, HF）作为21世纪心血管领域的“流行病”，其临床管理面临着巨大的挑战。这种复杂的临床综合征不仅具有极高的发病率和死亡率，更显著的特征在于其病程的异质性与不稳定性——患者常在临床稳定期与急性失代偿期（Acute Decompensated Heart Failure, ADHF）之间反复波动，导致了臭名昭著的“旋转门”现象，即极高的30天再入院率。据统计，约20%至25%的心衰患者在出院后一个月内会再次入院，这不仅耗费了巨大的医疗资源，也严重损害了患者的预后 1。
在此背景下，精准预测心衰患者的再入院风险已成为医疗人工智能领域的“圣杯”。然而，传统的预测模型往往存在显著的局限性。早期的统计学模型（如LACE指数）主要依赖于静态的结构化数据（如入院时的年龄、共病指数），忽略了住院期间病情的动态演变。随后的深度学习尝试（如RNN/LSTM）虽然引入了时序维度，但在处理多模态异构数据（如将非结构化的出院小结、高维的医学影像与时序生命体征融合）时显得力不从心，且缺乏临床可解释性 1。
本报告所探讨的 HyCF-TFM（Hybrid Clinical Framework with Transformer Fusion Model）框架，代表了临床预测模型从被动感知向 主动认知（Agentic AI） 的跨越。该框架不仅利用 Transformer 强大的注意力机制解决了长程依赖和多模态语义对齐问题，更引入了 意图树（Intent Tree） 和 MLLM Agent（多模态大语言模型智能体） 的概念 1。通过模拟人类医生的“思维链”（Chain-of-Thought），HyCF-TFM 将宏观的“风险预测”任务分解为“血流动力学评估”、“淤血状态分析”、“社会支持审查”等具体的临床意图，从而实现了数据驱动与知识驱动的深度融合。本报告将详细阐述基于该框架的实验设计、代码架构及合成数据构造策略，旨在为构建下一代心衰风险预警系统提供详尽的实施蓝图。
2. HyCF-TFM 理论架构解析与意图驱动机制
HyCF-TFM 的核心在于将临床决策过程结构化。不同于传统的端到端黑盒模型，该框架通过显式的 意图树（Intent Tree） 来调度底层的特征提取引擎，并通过 纵向 Transformer 融合模块 实现时空数据的深度整合。
2.1 动态意图树（Dynamic Intent Tree）的逻辑拓扑
在 HyCF-TFM 中，“意图”并非抽象的概念，而是具体的计算指令。针对心衰风险预测，意图树的设计严格遵循临床指南（如 ESC 或 ACC/AHA 指南）中的评估逻辑 1。
根意图 (Root Intent)： 全局目标设定为“评估患者 T0 时刻（出院时）的30天再入院风险”。
一级子意图 (Level-1 Sub-Intents)：
意图 A (文本/SDoH)： “分析社会决定因素与依从性”。此节点调度 NLP 智能体扫描出院小结（Discharge Summary），提取关于服药依从性、家庭支持、经济状况等非医疗风险因子。
意图 B (时序/生理)： “评估病情演变趋势（T1 $\to$ T0）”。此节点调度 LSTM/GRU 或 Time-Series Transformer 引擎，分析住院期间（T1 至 T0）的生命体征（血压、心率）和实验室指标（BNP、肌酐）的波动率。
意图 C (影像/解剖)： “评估肺淤血与心脏重构”。此节点调度视觉引擎（如 MN-STDT 中的 CNN/ViT 模块），对比入院与出院时的胸部 X 光片（CXR），量化肺水肿的消退情况 1。
融合节点 (Fusion Node)： 这是一个基于 Attention 的决策层，它不仅加权聚合上述三个通道的特征向量，还负责生成基于证据的解释（例如：“尽管生化指标 B 好转，但文本 A 显示极差的依从性，故风险评分上调”）。
2.2 纵向多模态 Transformer 融合 (TFM) 机理
TFM 模块是处理 EHR 数据不规则性和异构性的核心。
2.2.1 距离感知时间编码 (Distance-Aware Temporal Encoding)
临床事件的发生是不均匀的。例如，BNP 可能在入院第一天测一次，第四天测一次，而心率则是每小时记录一次。标准的 Transformer 位置编码（Positional Encoding）假设输入是等间距的，这在 EHR 中并不适用。HyCF-TFM 采用了距离感知机制：


$$PE(t, 2i) = \sin\left(\frac{\phi(\Delta t_{curr, prev})}{10000^{2i/d_{model}}}\right)$$

其中 $\phi(\Delta t)$ 是一个可学习的时间衰减函数，它使得模型能够理解“昨天”的肌酐升高比“五年前”的心梗对当前的再入院风险具有更大的权重，同时也保留了对远期关键病史的检索能力 1。
2.2.2 跨模态注意力交互 (Cross-Modal Attention)
为了实现真正的融合而非简单的特征拼接（Concatenation），TFM 引入了跨模态注意力机制。
Query ($Q$): 来自临床文本的语义向量（例如，“呼吸困难”的 Embedding）。
Key ($K$) / Value ($V$): 来自时序数据或影像的特征序列。
机制： 当文本中提到“容量过负荷”时，模型会自动增大对“近期体重增加”或“CXR 肺门模糊”等特征的注意力权重。这种机制模拟了医生“查阅病历 $\to$ 验证检查结果”的循证过程 1。

4. 合成数据构造：解决数据稀缺与隐私壁垒
为了满足“构造足量相关数据”的实验要求，我们必须引入合成数据生成（Synthetic Data Generation, SDG）技术。这不仅能扩充训练集（Data Augmentation），还能模拟极端或罕见的心衰表型，增强模型的鲁棒性。
4.1 结构化时序数据生成：TabDDPM
对于通道 B 的时序数据，传统的 GAN（如 TimeGAN）容易出现模式崩溃。本实验设计采用 Tabular Denoising Diffusion Probabilistic Models (TabDDPM)，这是一种基于扩散模型的生成方法，能更好地捕捉复杂的时序相关性 11。
生成逻辑：
前向过程： 向真实的患者时序矩阵 $X_0$ 逐步添加高斯噪声，直到变为纯噪声 $X_T$。
反向过程： 训练一个神经网络（通常是 U-Net 变体）来预测噪声，从而从随机噪声中“去噪”还原出逼真的生理参数轨迹（例如，生成一条合理的、随利尿剂使用而下降的体重曲线）。
条件控制： 将患者的静态特征（年龄、性别、心衰类型）作为 Condition 注入模型，确保生成的时序数据符合特定的人口学特征。
4.2 非结构化文本生成：Context-Aware LLM Generation
对于通道 A 的出院小结，单纯的文本生成是不够的，必须保证文本描述与生成的结构化数据（如 BNP 值）在语义上一致。我们采用 Retrieval-Augmented Generation (RAG) 结合微调的 LLM。
Prompt 设计模板：: 你是一位专业的心内科医生。基于以下患者的生理数据，撰写一份详细的出院小结。[Context]: 患者年龄: 75岁; 性别: 男; 入院BNP: 1500 pg/mL -> 出院BNP: 300 pg/mL; 肌酐: 1.2 -> 1.8 (恶化); CXR显示: 肺水肿显著吸收。: 请生成包含“住院经过”、“出院诊断”和“出院医嘱”的小结。重点描述心肾综合征的处理和利尿剂调整。
实施： 使用开源的 Llama-3-8B-Instruct 或针对医疗微调的 Meditron-70B 模型，批量生成与 TabDDPM 生成的结构化数据相匹配的文本记录 7。
4.3 合成数据质量评估 (SynthEHRella 框架)
为了验证合成数据的有效性，必须运行以下评估指标 13：
保真度 (Fidelity)： 比较真实数据与合成数据的边缘分布（使用 Kolmogorov-Smirnov 测试）和相关性矩阵（Pearson 相关系数）。确保合成的“BNP”与“死亡率”之间的相关性与真实世界一致。
效用性 (Utility - TSTR)： Train on Synthetic, Test on Real。在合成数据上训练一个 XGBoost 模型，并在真实 MIMIC-IV 测试集上评估其 AUC。如果性能下降在 5% 以内，则认为数据具有极高的效用。
隐私性 (Privacy)： 进行成员推理攻击（Membership Inference Attack），确保生成的记录不会泄露真实患者的身份信息。

6. 实验对比与评估指标设计
为了科学地验证 HyCF-TFM 的性能，我们需要将其与现有的一流模型（SOTA）进行全方位的对比。
6.1 基线模型 (Baselines)
单模态基线：
LR (Logistic Regression): 仅使用 LACE 指数特征（L=住院时长, A=急诊入院, C=共病, E=急诊次数），代表传统临床评分。
XGBoost: 仅使用结构化 EHR 数据，这是目前竞赛中最强的非深度学习基线。
ClinicalBERT: 仅使用出院小结文本进行微调预测，评估文本模态的独立价值。
多模态基线：
MedFuse (LSTM + CNN): 经典的晚融合架构，分别处理时序和影像，最后在全连接层融合。
MN-STDT (SOTA): 针对心衰死亡率预测设计的时空解耦 Transformer，是本实验最强劲的竞争对手 1。
6.2 评估指标 (Metrics)
鉴于再入院数据通常存在严重的类别不平衡（正样本约占 20%），单纯的准确率（Accuracy）毫无意义。我们采用以下核心指标：
AUROC (Area Under Receiver Operating Characteristic Curve): 衡量模型的整体区分度。
AUPRC (Area Under Precision-Recall Curve): 关键指标。在临床场景中，我们更关心在高风险报警（Recall）的同时，不要产生过多的误报（Precision）。AUPRC 能更真实地反映模型在不平衡数据上的性能 1。
F1-Score: 精确率与召回率的调和平均数。
Brier Score: 衡量预测概率的校准度（Calibration）。一个好的临床模型给出的“80%风险”应该对应真实世界中 80% 的概率，这对医生决策至关重要 14。
6.3 消融实验 (Ablation Study)
为了证明 HyCF-TFM 中各个组件的有效性，需进行消融测试：
w/o Intent Agent: 去掉意图树，直接将所有特征输入 Transformer。验证“意图驱动”是否提升了推理效率或准确性。
w/o TFM (Cross-Attention): 将跨模态注意力替换为简单的 Concat。验证 Transformer 融合机制的优越性。
w/o Text/Image: 分别移除文本或影像模态，量化各模态对预测结果的增益（Marginal Contribution）。
7. 结论与展望
本实验设计通过 HyCF-TFM 框架，创新性地将心衰风险预测从单纯的数据拟合提升到了意图驱动的认知推理层面。通过集成 MIMIC-IV 的多模态数据，利用 TabDDPM 和 LLM 构建高保真的合成数据，不仅解决了数据隐私和稀缺问题，更为模型的泛化能力提供了保障。
预期结果将证明，基于 Transformer 的纵向多模态融合 能够显著优于传统的单模态或简单融合模型（预计 AUROC 提升 0.03-0.05）。更重要的是，意图树 机制将赋予模型前所未有的可解释性，使其能够输出类似于“因肺部影像恶化且利尿剂反应不佳导致高风险”的自然语言解释，这将极大地促进 AI 辅助诊断系统在真实临床环境中的落地与信任构建。未来工作可进一步探索将强化学习引入 Agent，使其能够主动建议进行某些缺失的检查（Active Sensing），从而实现真正的交互式临床辅助。

## 分节 1

实验三SQL数据库的更新与视图
一、实验目的
SQL语言以数据库的基本表更新通过DML函数实现，包括插入INSERT，更新UPDATE，删除DELETE三个函数。但是考虑到数据库的安全需求，通常用户的查询与更新操作均在视图上完成。
本次实验的目的是实践数据库的更新代码的设计，并分别在基本表与视图上实践查询与更新代码。以实验一创建的数据库为基础完成任务。
二、实验内容
1．数据的插入与删除：
数据插入的语句格式为：
INSERT
INTO      <表名> [(<属性列1>[,<属性列2 >…)]
VALUES   (<常量1> [,<常量2>]… );
数据删除的语句格式为：
DELETE
FROM     <表名>
[WHERE   <条件>];
请编程完成任务：

b) 查询1月1日至4日全市平均空气质量数据，并插入草滩区数据表；


2. 数据的更新：
数据更新的语句格式为：
UPDATE    <表名>
SET        <列名>=<表达式>[,<列名>=<表达式>]…
[WHERE    <条件>];
请编程完成任务：

b) 使用平均CO指数更新1月3日的CO指数；


3. 视图创建及更新：
视图创建的语句格式为：
CREATE  VIEW  <视图名>  [(<列名>  [,<列名>]…)]
                 AS       
<SELECT子查询>
               [WITH  CHECK  OPTION];


视图更新的语句格式为：
UPDATE    <视图名>
SET        <列名>=<表达式>[,<列名>=<表达式>]…
[WHERE    <条件>];

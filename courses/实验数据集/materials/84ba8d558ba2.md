## 分节 1

实验二SQL数据库的查询
一、实验目的
SQL语言以数据库查询为核心任务。基本的查询操作可以分为单表查询、多表查询、嵌套查询与视图查询四类，并在查询中使用聚集函数、分组、排序辅助查询或结果的显示。
SQL查询语句为SELECT，其基本代码形式为：
SELECT [ALL|DISTINCT] <目标列表达式>[,<目标列表达式>] …
FROM <表名或视图名>[,<表名或视图名> ]…|(SELECT 语句)  
                     [AS]<别名>
[ WHERE <条件表达式> ]
[ GROUP BY <列名1> [ HAVING <条件表达式> ] ]
[ ORDER BY <列名2> [ ASC|DESC ] ];

图1 SQL Studio编程界面
SQL编程是针对数据库的查询程序编写与执行，界面操作为右键点击数据库名称 - 点击新建查询，在生成的编辑窗口中编写程序，如图1所示。
以SQL Studio为例，A区域为数据列表，B区域为编程区域，C区域为查询结果显示。
本次实验的目的是实践数据库的查询(SELECT)代码的设计与执行，并根据实验一导入的数据库，完成数据查询任务。
二、实验内容
1．单表查询：
a) 查询长安区2013年3月12日长安区空气质量的详细信息；

b) 查询草滩PM25指数小于150的日期、PM25和PM10指数，并将结果按照PM10指数降序排列；

c) 查询纺织城各污染指数对应的天数以及无监测结果的天数；

2. 多表查询：
查询全市平均CO指数小于50且市体育场无CO指数监测数据的日期及全市平均CO指数与全市平均空气污染指数；

3. 嵌套查询：
查询市体育场PM25大于本地平均PM25指数的日期及PM25指数与空气污染指数；


三、实验任务
1．根据实验内容要求设计SQL查询代码；
2．在编程界面分别新建查询并运行代码；
3．检验查询结果是否正确。

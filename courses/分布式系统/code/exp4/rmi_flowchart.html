💡 节点关系说明：

  • 客户端 GUI (RMIClient)： 完全不包含任何 JDBC 代码，仅依靠引入 IRemoteStudentService.java 接口约束来调用方法。
  • RMI Registry： 相当于中介黄页。服务端在这里“挂牌”，客户端通过“挂牌名”找到真正的远程处理对象。
  • 网络序列化/反序列化： 客户端的参数 (如 Student 对象) 到服务端的传输是在不同 Java 虚拟机(JVM)和不同内存地址空间进行的，所有对象必须被序列化传输，这就是实体类需实现 Serializable 的原因。
  • 服务端与数据库 (Server & MySQL)： 真正将逻辑请求转换为 SQL 指令的地方，也是系统中唯一和 .env 及 database 直接通讯的节点，确保了数据库高安全性。

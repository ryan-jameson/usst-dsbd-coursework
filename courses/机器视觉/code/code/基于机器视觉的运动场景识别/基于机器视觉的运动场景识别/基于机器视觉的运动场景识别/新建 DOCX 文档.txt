本课题任务为构建一套面向体育赛事理解的机器视觉分析框架，以解决复杂竞技环境下运动场景的精准感知与语义解构问题。针对足球、篮球、排球三类典型团队竞技运动，将基于场边摄像机采集的数据集，拟通过研究跨场景泛化的目标检测与多目标跟踪算法，实现对运动员、球体及关键场地标识的稳定识别；通过挖掘长时序时空特征，区分进攻、防守、定位球等不同战术状态。最终目标是建立一套适用于球类比赛规则的场景理解模型，为自动战术分析、精彩片段剪辑及智能裁判辅助系统提供核心技术支撑，推动体育视频分析的智能化与自动化进程。



注：可以选择对三种运动进行自适应规则逻辑的运动场景识别研究，也可以专注某一项运动，结合规则、战术等先验知识进行精细化分析。



附件分别为篮球、足球、排球的比赛录像(已完成分帧)

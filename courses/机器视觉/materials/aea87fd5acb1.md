## 分节 2

摘

要

本课程设计面向足球比赛视频的自动分析需求，设计并实现了一套由 PC 端机器
视觉处理、桌面程序展示、USB 通信和 M55 开发板输出组成的足球赛事理解系统。
针对足球比赛中球员数量多、目标遮挡频繁、足球尺度小以及比赛事件依赖连续时序
信息等问题，系统首先采用 COCO 数据集预训练的 YOLOv8n 模型对目标比赛片段进
行逐帧检测，将模型输出的 person 和 sports ball 类别分别映射为球员与足球候选目标，
并记录边界框、置信度和中心点等信息。在此基础上，系统利用交并比构建相邻帧目
标匹配矩阵，通过匈牙利算法完成全局关联，为检测目标分配连续轨迹编号，并保存
其历史位置，从而提取球员分布、运动速度、运动方向、局部聚集程度和足球位置变
化等时序特征。
在赛事理解环节，系统根据球员进入对方半场的比例、足球周边球员数量、轨迹
平均位移和足球连续位置变化等特征，形成阵地进攻、阵地防守、快速反击和定位球
等候选比赛状态。为减少单帧检测波动造成的误触发和重复输出，系统设计了
EventGate 事件门控机制，通过连续帧稳定确认、置信度过滤和冷却时间控制，将高
频视觉结果转换为低频、结构化且可解释的比赛事件。对于目标比赛片段，程序按照
文件名顺序读取连续图像，依次完成检测、跟踪、事件判断和结果记录，并在 PC 桌
面程序中同步显示原始画面、检测叠加画面、处理进度和传输状态，同时生成 CSV
与 JSONL 事件报告。
在应用输出方面，有效事件被封装为 FBP1 数据帧，通过 USB CDC 发送至 M55
开发板。开发板端完成事件帧接收、内容校验、事件状态更新及 LVGL 页面刷新输入，
接收成功后向 PC 端返回 ACK。在 60 帧目标片段测试中，系统产生并发送 4 个有效
事件，全部获得开发板 ACK，稳态单帧处理时间约为 65—100 ms。课程设计最终完
成了从比赛片段输入、目标检测、跨帧跟踪和事件识别，到桌面展示、结果记录与开
发板接收的完整数据流程，体现了通用目标检测、轻量时序分析与嵌入式应用输出的
协同实现。
关键词：足球赛事理解；YOLOv8n；多目标跟踪；匈牙利算法；事件识别；USB CDC；
M55 开发板

## 分节 3

ABSTRACT
This course design focuses on the automatic analysis of football match videos and
presents a football match understanding system integrating PC-based machine vision
processing, desktop visualization, USB communication, and M55 development-board
output. To address challenges such as numerous players, frequent occlusion, the small size
of the football, and the dependence of match events on temporal information, the system
first uses a YOLOv8n model pretrained on the COCO dataset to process the target match
clip frame by frame. The person and sports ball classes are mapped to player and football
candidates, respectively, while bounding boxes, confidence scores, and center coordinates
are recorded.
An intersection-over-union matrix is then constructed to associate targets between
adjacent frames. The Hungarian algorithm performs global assignment, assigns continuous
trajectory IDs, and preserves historical positions. These trajectories are used to extract
temporal features, including player distribution, movement speed and direction, local
player density, and changes in football position.
During event understanding, the system generates candidate match states — such as
positional attack, positional defense, rapid counterattack, and set-piece situations —
according to the proportion of players entering the opposing half, the number of players
near the football, average trajectory displacement, and changes in the football’s position.
To reduce false triggers and repeated outputs caused by frame-level fluctuations, an
EventGate mechanism applies multi-frame stability confirmation, confidence filtering, and
cooldown control. Consequently, high-frequency visual results are converted into
low-frequency, structured, and interpretable match events.
For the target match clip, the program reads consecutive images in filename order and
sequentially performs detection, tracking, event inference, and result recording. The PC
desktop application simultaneously displays the original frames, detection overlays,
processing progress, and transmission status, while exporting event reports in CSV and
JSONL formats.
For application output, valid events are encoded as FBP1 data frames and transmitted
to the M55 development board through USB CDC. The development-board software
performs frame reception, content verification, event-state updates, and provides input for
LVGL page refreshing. An ACK is returned to the PC after successful reception. In a
60-frame test, the system generated and transmitted four valid events, all of which were
acknowledged by the development board. The steady-state processing time was
approximately 65–100 ms per frame. This course design implements a complete data flow
from match-clip input, target detection, cross-frame tracking, and event recognition to
desktop visualization, result recording, and development-board reception, demonstrating
the coordinated application of general-purpose object detection, lightweight temporal
analysis, and embedded output.
KEY WORDS: football match understanding; YOLOv8n; multi-object tracking;
Hungarian algorithm; event recognition; USB CDC; M55 development board

1.1 研究背景与意义
足球运动作为全球参与度最高的体育项目，其赛事分析对于球队战术调整、球员
表现评估、裁判辅助决策具有重要价值。传统足球赛事分析主要依赖以下方式：
传统人工赛事分析存在缺陷：效率低下，分析师需逐帧观看比赛录像，手动记录
球员跑动轨迹、传球次数、射门机会等数据，一场 90 分钟的比赛分析需耗费数小时；
主观性强，不同分析师对同一战术场景的理解存在差异，导致分析结果不一致；数据
维度有限，人工记录难以捕捉球员实时速度、加速度、空间位置关系等细粒度数据；
实时性不足，人工分析无法在比赛进行中提供即时反馈，难以支持临场战术调整
随着体育产业数字化转型加速，足球俱乐部、赛事转播商、体育科技公司对智能
分析系统的需求日益迫切：职业球队需要量化分析工具评估球员体能状态和战术执行
效果，转播机构需要自动生成精彩片段、战术可视化等增值内容，裁判辅助系统需要
视觉技术支持越位判定、进球确认等关键判罚。
但与其他体育项目相比，足球场景具有以下特殊性：目标尺度差异大，远距离拍
摄时足球仅占几个像素，而近景球员占据画面大部分区域；密集遮挡频繁，禁区争抢
时多名球员相互遮挡，导致目标检测和跟踪失效；场地背景复杂，草坪纹理、光照变
化、阴影干扰等增加检测难度；运动速度快，球员冲刺速度可达 30km/h 以上，足球
飞行速度更高，需要算法具备高帧率处理能力；战术语义复杂，足球战术涉及球员间
的协同配合，需要建模复杂的时空交互关系

1.2 国内外研究现状
1.2.1 足球目标检测
目标检测是足球赛事理解的基础，国内外学者针对足球场景提出了多种检测方案：
早期研究基于传统方法的检测，主要采用颜色阈值、形状匹配、背景差分等传统
计算机视觉方法。例如，Baltieri 等利用 HSV 颜色空间分离球员和场地，结合模板匹
配识别足球。此类方法在简单场景下有效，但鲁棒性差，难以应对遮挡和光照变化。
随着深度学习技术发展，基于卷积神经网络的目标检测方法成为主流。Redmon
等提出的 YOLO 系列算法因其高效性被广泛应用于足球检测任务。YOLOv5 和
YOLOv8 在 COCO 数据集上表现优异，但直接应用于足球场景时存在小目标检测能
力不足的问题。针对此问题，部分研究者通过增加小目标检测层、使用高分辨率输入
等方式进行优化。
综上，现有方案缺陷在于，通用目标检测模型对足球等小尺度目标检测精度较低；
缺乏针对球衣颜色区分两队球员的专用方案；未充分利用足球场地的几何约束信息

1.2.3 时序战术理解
战术理解是在感知层基础上提取高层语义信息的任务。
早期研究以基于规则的方法为主，通过人工定义规则判断战术状态，如根据控球
方位置判断攻防状态。此类方法易于解释但灵活性差，难以覆盖复杂战术场景。

2.1 目标检测基础
2.1.1 YOLOv8 网络结构
YOLOv8 是 Ultralytics 公司于 2023 年发布的目标检测模型，采用 Anchor-free 设
计，网络结构主要包含以下部分：
Backbone：YOLOv8 使用 CSPDarknet 作为骨干网络，包含多个 C2f 模块。C2f
模块将输入特征图分为两个分支，分别经过多个卷积层后拼接，既保证了特征提取能
力，又控制了计算量。
Neck：Neck 部分采用 PAN（Path Aggregation Network）结构，通过自顶向下和自
底向上的特征融合，增强多尺度特征表达能力。
Head：YOLOv8 的检测头采用解耦设计，将分类和回归任务分离，分别由不同的
卷积层处理。输出层预测目标中心坐标、宽高、置信度和类别概率。
2.1.2 多尺度检测机制
YOLOv8 通过三个不同尺度的检测分支实现多尺度目标检测：
大尺度分支：检测小目标，感受野较小，保留更多细节信息
中尺度分支：检测中等目标，平衡细节和上下文信息
小尺度分支：检测大目标，感受野较大，获取更多全局信息
2.1.3 小目标优化方案适配足球
针对足球小尺度特点，本文采用以下优化方案：
增加小目标检测层：
在原有的三个检测分支基础上，增加一个更高分辨率的检测层，专门处理足球等
极小目标。该层直接连接 Backbone 的浅层特征，保留更丰富的细节信息。
调整 Anchor 尺寸：
针对足球直径约为 22cm 的实际尺寸，计算不同拍摄距离下足球在图像中的像素
范围，据此调整 Anchor 尺寸分布，使模型更关注小尺度目标。
高分辨率输入：
将输入图像分辨率从默认的 640×640 提升至 1280×1280，增加小目标的像素占
比，提升检测精度。

2.2 多目标跟踪
2.2.1 ByteTrack 算法原理
ByteTrack 是 2021 年提出的高效多目标跟踪算法，其核心思想是利用低置信度检
测框辅助跟踪，将检测结果分为高置信度框（用于初始化新轨迹）和低置信度框（用
于关联现有轨迹）。对每个活跃轨迹，使用卡尔曼滤波器预测下一帧的位置。卡尔曼
滤波包含预测和更新两个阶段；在预测阶段，基于上一帧状态预测当前帧位置。利用
当前帧检测结果修正预测值。提取目标的外观特征（如颜色直方图、HOG 特征），
通过计算特征相似度辅助轨迹关联。在匹配策略上，采用匈牙利算法进行轨迹-检测
框匹配，综合考虑位置距离和外观相似度。

2.2.2 ID 切换抑制策略
ID 切换是指同一目标在连续帧中被分配不同 ID 的现象，会导致轨迹断裂。本文

2.5 足球竞赛规则与战术定义
2.5.1 进攻/防守状态分类
进攻状态下，控球方试图突破对方防线，创造射门机会。特征包括：球员向对方
球门方向移动、传球频率高、进攻三区（对方半场靠近球门区域）球员密集。
防守状态下，非控球方组织防线，阻止对方进攻。特征包括：球员回撤至本方半
场、阵型紧凑、拦截意图明显。
攻防转换情况下，控球权发生转移的瞬间，如抢断、解围后的反击场景。
2.5.2 细粒度战术分类
阵地进攻：进攻方通过短传配合逐步推进，控制比赛节奏。
快速反击：防守方断球后迅速发动进攻，利用速度优势创造机会。
定位球：包括角球、任意球、点球等场景，具有固定的战术套路。
死球：比赛暂停状态，如界外球、球门球等。

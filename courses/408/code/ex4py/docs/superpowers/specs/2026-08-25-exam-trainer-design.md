# 085411 Python 机试七天训练营设计

## 目标
在 `E:\平时作业\408\ex4py` 建立离线命令行训练系统，使已有 Python 基础但算法训练较少的学习者，在一周内完成从语法与输入输出到算法识别、限时编码和复盘的闭环训练。

## 总体架构
`main.py` 只负责启动 CLI。`trainer/` 分别承载题库读取、子进程判题、进度保存和命令分发。课程、题目与模板保持为可直接阅读的 Python/Markdown 数据文件，学习者的代码只写入 `workspace/`，系统更新不覆盖已存在的答题文件。

## 用户流程
1. `python main.py today 1` 查看当天目标、知识卡片和建议时间块。
2. `python main.py list 1` 查看题目与完成状态。
3. `python main.py start D1-01` 创建答题文件并显示题面。
4. `python main.py test D1-01` 运行公开样例；`submit` 运行公开和隐藏测试。
5. 失败后使用 `hint` 逐级查看“识别信号、关键步骤、伪代码”。
6. 使用 `solution` 主动查看参考实现和复杂度；此行为写入进度。
7. `status` 汇总完成率、错误类型和薄弱标签；`mock` 给出模拟卷流程。

## 题库
题库固定 60 道，每题含 ID、天数、标题、难度、标签、题面、输入输出、约束、公开测试、隐藏测试、三级提示、代码骨架、参考实现、复杂度与易错点。Day 1 为 12 道基础题；Day 2 为 10 道数据结构；Day 3、4 各 10 道核心算法；Day 5 为 6 道综合模拟；Day 6 为 8 道薄弱点强化；Day 7 为 4 道最终模拟与巩固。

## 判题
判题器用当前 Python 解释器启动 `solution.py`，通过 stdin 传入测试数据，捕获 stdout/stderr，并设置每个用例的超时。输出比较忽略行尾空格和文件末尾空行，但不忽略内部空格和行序。结果分类为 AC、WA、RE、TLE、MISSING。

## 进度与错误恢复
进度保存为 UTF-8 JSON，记录尝试次数、AC 状态、错误类型计数、提示等级、是否查看答案和最近提交时间。写入使用临时文件替换，避免半写入。JSON 损坏时将原文件重命名为带时间戳的备份，再创建空进度；答题文件永不自动删除。

## 课程与模板
Day 1–7 各有一份中文讲义，统一包含“今日目标、2+3+1 小时安排、识别信号、核心知识、当天清单、复盘问题”。模板库包含快读、排序、二分、双指针、滑动窗口、栈、BFS、DFS、树遍历、并查集、前缀和/差分、回溯、0/1 背包和序列 DP。

## 安全边界
本工具不是安全沙箱，只应运行学习者自己编写的代码。子进程有时间限制，但不限制文件、网络和内存访问。工具不会访问网络，也不会执行题库中的任意命令。

## 测试
单元测试覆盖题库数量与字段、输出规范化、AC/WA/RE/TLE、工作区文件不覆盖、提示升级、进度持久化与损坏恢复。CLI 冒烟测试覆盖 `doctor`、`list`、`start` 和无效题号。最终执行标准库 `unittest`、编译检查和关键命令。

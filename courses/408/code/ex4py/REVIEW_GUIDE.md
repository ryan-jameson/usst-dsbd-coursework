# 085411 Python 复习题库使用指南

复习库不是第二套“新知识课程”，而是把 20 个高频算法原型各换三种题面和边界，让你重复经历“识别 → 独立编码 → 边界检查”。原核心题用 `D` 开头，复习题用 `R` 开头。

## 三遍复习法

每个原型有三题，例如 `R08-01`、`R08-02`、`R08-03`：

1. **标准复现（-01）**：不限时，但必须先写一句算法信号，不看旧代码。
2. **边界变化（-02）**：隔至少半天，限时 20 分钟，重点测重复值、负数、空结果、不可达等边界。
3. **场景迁移（-03）**：放入混合题单，不告诉自己属于什么算法，只根据题面识别。

同一原型不要连续完成三题。连续做容易依赖短期记忆；隔开后才能检验是否真的形成了模板。

## 命令

```powershell
# 查看 10 个复习组
python main.py review list

# 查看动态规划组的 6 题
python main.py review list dp

# 推荐该组第一道尚未通过的题
python main.py review next dp

# 从 10 个组各取一道未通过题，生成交叉复习单
python main.py review mix 10

# R 题复用原有做题命令
python main.py start R19-01
python main.py test R19-01
python main.py submit R19-01
python main.py hint R19-01
```

`review mix` 只创建不存在的答题文件，不覆盖你的代码。`status` 会分别显示核心 60 题和复习 60 题进度。

## 10 个复习组

| 组名 | 算法原型 | 对应题号 |
|---|---|---|
| `basic` | 线性统计、字符频率 | R01～R02 |
| `sort_hash` | 多关键字排序、哈希配对计数 | R03～R04 |
| `stack_queue` | 括号栈、单调栈 | R05～R06 |
| `pointer_binary` | 有序双指针、二分计数 | R07～R08 |
| `range` | 前缀和、差分 | R09～R10 |
| `grid` | 网格连通块、无权最短路 | R11～R12 |
| `tree_graph` | 树遍历、并查集 | R13～R14 |
| `shortest_order` | 拓扑排序、Dijkstra | R15～R16 |
| `search_greedy` | 子集回溯、区间贪心 | R17～R18 |
| `dp` | 不相邻选择、0/1 背包 | R19～R20 |

## 14 次练习安排

每次 90～150 分钟，不要求在七天核心训练结束前全部完成。

1. `review mix 10`：诊断，不看提示，记录完全没思路的组。
2. `basic`：完成两个 -01，再做一个 -02。
3. `sort_hash`：完成两个 -01，再做一个 -02。
4. `stack_queue`：完成 6 题，单调栈至少手写两次。
5. `pointer_binary`：完成 6 题，二分必须统一边界写法。
6. `range`：完成 6 题，自己造一个 `l=1,r=n` 用例。
7. `grid`：完成两个 -01/-02，次日再做两个 -03。
8. `tree_graph`：完成 6 题，口述节点状态和集合不变量。
9. `shortest_order`：完成 6 题，区分无权 BFS 与非负权 Dijkstra。
10. `search_greedy`：完成 6 题，回溯写撤销，贪心写选择理由。
11. `dp`：完成 6 题，每题先写状态、转移、初值、顺序。
12. `review mix 20`：交叉识别，每题 18～20 分钟。
13. 用 `status` 找未 AC 题，只重写失败题，不查看旧答案。
14. `review mix 30`：作为半套综合机试，统一结束后提交和复盘。

## 每题的完成标准

- 30 秒内说出主要算法与复杂度上界。
- 独立写出 stdin/stdout 程序，不复制参考答案。
- 公开样例通过后，自己再造至少两个边界用例。
- `submit` 达到 AC。
- 第二天能在不看旧代码时重写核心循环。

如果一题查看了三级提示或答案，不把它计作“真正掌握”。隔一天重新删除思路记忆、保留文件，再从空白处重写一个新版本进行自测。

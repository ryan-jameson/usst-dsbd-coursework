## DP 四行纸
```text
状态：dp[...] 表示什么
转移：当前状态从哪些更小状态得到
初值：没有选择或最小规模时是什么
顺序：依赖必须先被计算；0/1 背包容量倒序
```

## 高频陷阱
- 求最小值初始化为无穷，求方案数通常 `dp[0]=1`。
- 一维压缩后覆盖了仍需使用的旧状态。
- 把连续子数组和不连续子序列混为一谈。
- 看到“最优”就直接贪心，却无法解释反例。

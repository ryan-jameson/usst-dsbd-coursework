## 高频语法
- `a.sort(key=..., reverse=...)` 原地修改并返回 `None`；`sorted(a)` 返回新列表。
- `dict.get(key, 0)` 做计数；`set` 做去重和 O(1) 期望成员判断。
- 字符串不可变；大量拼接用列表收集后 `''.join(parts)`。
- 递归必须有终止条件；图/树深度未知时优先考虑迭代或设置合理递归深度。

## 复杂度条件反射
- 一次完整遍历：O(n)；嵌套完整遍历：通常 O(n²)。
- 排序：O(n log n)；哈希查询：期望 O(1)；`list.pop(0)`：O(n)。
- n≈10⁵ 时通常应控制在 O(n log n)；n≈10³ 才可能接受 O(n²)。

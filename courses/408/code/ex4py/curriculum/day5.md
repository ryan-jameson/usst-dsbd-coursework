# Day 5｜真实机试模拟

## 今日结果
形成固定流程：读题标注输入输出与约束 → 选择算法 → 写样例 → 编码 → 边界测试 → 提交与复盘。

## 执行方式
- 上午：`python main.py mock 1`，连续 120 分钟。
- 下午：`python main.py mock 2`，连续 120 分钟。
- 每套结束后逐题 `submit`，不要在计时中查看 `hint` 或 `solution`。

## 时间规则
- 前 10 分钟通读全部题，按“稳拿—可做—风险”排序。
- 简单题卡 25 分钟仍无进展就切换；中等题卡 40 分钟切换。
- 每题至少留 5 分钟检查：最小输入、全相等、全负、不可达、重复边、空结构。

## 错误分类
- READ：题意/输入读错。
- ALG：算法选择错误或复杂度超限。
- IMP：实现错误，如下标、状态更新、变量覆盖。
- EDGE：边界遗漏。
- IO：多空格、多组数据、输出格式。
- TIME：时间分配失控。

复盘只写可执行规则，例如：“BFS 必须入队即标记”，不要写“下次细心”。

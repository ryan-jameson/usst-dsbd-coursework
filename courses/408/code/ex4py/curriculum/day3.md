## 状态四问
1. 一个节点/状态由什么变量唯一描述？
2. 从当前状态能转移到哪些邻居？
3. 何时标记访问，如何避免重复？
4. 到达目标后立即返回，还是要遍历全部状态？

## 选择规则
- 无权最短路：BFS；连通块统计：DFS 或 BFS。
- 全部方案：回溯；只问方案数且状态重复多：考虑 DP。
- “最小可行值/最大可行值”且验证函数单调：二分答案。

## 编程题统一主线

1. 选择原始、多项式或高斯/RBF 基函数。
2. 构造设计矩阵 `Φ`，首列全 1 表示偏置。
3. 最小二乘闭式解使用 `w = pinv(Φ) @ y`；梯度下降使用 `grad = Φ.T @ (Φ @ w - y) / N`。
4. 计算预测 `y_hat = Φ @ w`，最后报告均方误差 MSE。

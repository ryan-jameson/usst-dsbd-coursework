# 第一部分 名词解释（每题 4 分的写法）

## 1.1 通用近似定理

### 可直接抄写

> 通用近似定理是指：设激活函数 φ(·) 为非常数、有界、单调递增的连续函数，对定义在 D 维单位超立方体 [0,1]^D 上的任意连续函数 f(x) 和任意给定精度 ε>0，都存在一个只含一个隐藏层、隐藏单元数为 M 的前馈神经网络 F(x)=Σ(v_m φ(w_m^T x+b_m))，使得对定义域内任意 x 都有 |F(x)-f(x)|<ε。它说明隐藏单元足够多的前馈神经网络具有逼近任意连续函数的表示能力；但该定理不保证怎样找到这些参数，也不保证网络最优、易训练或泛化良好。

### 得分点

- 对象：有界闭集上的连续函数。
- 条件：至少一个隐藏层，合适的非线性激活函数，隐藏单元足够多。
- 结论：可以达到任意给定的逼近精度。
- 边界：只说明“存在”和“表示能力”，不说明训练算法、最优性与泛化性。

### 公式

F(x)=Σ_{m=1}^M v_m φ(w_m^T x+b_m)，且 |F(x)-f(x)|<ε。

教材补充：通用近似性质也适用于 ReLU；网络能力强也意味着更容易在训练集上过拟合，需要经验风险最小化和正则化。

## 1.2 感受野

### 可直接抄写

> 感受野是指能够影响某个神经元输出的输入区域。在生物视觉系统中，一个神经元只会被视网膜上特定区域内的刺激激活；在卷积神经网络中，某层一个神经元的感受野是原始输入图像中所有可能影响该神经元的像素范围。卷积的局部连接使单层神经元只连接局部区域，随着卷积层、汇聚层的堆叠，深层神经元的感受野逐渐增大，从而能够组合更大范围的特征。

### 常用计算

从输入层开始令感受野 r_0=1、相邻神经元在输入上的间隔 j_0=1。第 l 层卷积核大小 k_l、步长 s_l，则

- j_l = j_{l-1} s_l；
- r_l = r_{l-1} + (k_l-1)j_{l-1}。

例：连续两层 3×3、步长均为 1 的卷积，感受野从 1×1 变为 3×3，再变为 5×5。

## 1.3 监督学习

### 可直接抄写

> 如果机器学习的目标是建模样本特征 x 与标签 y 之间的关系 y=f(x;θ) 或条件概率 p(y|x;θ)，并且训练集中每个样本都有标签，那么称为监督学习。按标签形式可分为回归、分类和结构化学习：回归标签为连续值，分类标签为离散类别，结构化学习的标签可以是序列、树或图等结构化对象。

训练集形式：D={(x^(n),y^(n))}_{n=1}^N。

## 1.4 无监督学习

### 可直接抄写

> 无监督学习是指从不包含目标标签的训练样本中，自动学习数据中有价值的结构、分布或表示。其训练集只有输入 D={x^(n)}_{n=1}^N，典型任务包括聚类、概率密度估计、特征学习和降维。无监督学习常通过建模 p(x) 或带隐变量 z 的 p(x|z)，并采用最大似然或最小重构误差等准则进行学习。

### 监督与无监督的核心区别

监督学习有标签，直接学习输入到目标的关系；无监督学习没有目标标签，主要发现数据自身的结构或分布。

## 1.5 概率图模型（候选名词）

### 可直接抄写

> 概率图模型是用图结构描述多元随机变量之间条件独立关系的概率模型。图中节点表示随机变量或随机变量组，边表示变量之间的概率依赖关系。它利用条件独立性把复杂的联合概率分布分解为若干简单的局部概率或势能函数，基本问题包括模型表示、参数/结构学习和概率推断。

## 1.6 欠拟合与过拟合（候选名词）

> 欠拟合是模型在训练集上误差仍然较高，说明模型拟合能力不足、偏差较大；可通过增加有效特征、提高模型复杂度、训练更充分或减小正则化强度缓解。过拟合是训练误差很低而验证/测试误差较高，说明模型过度记忆训练数据、方差较大；可通过增加数据、降低模型复杂度、增大正则化、数据增强、早停或集成学习缓解。

# 第二部分 填空与计算题

## 2.1 二维卷积运算（4 分）

### 教材定义

给定输入 X∈R^{M×N} 和卷积核 W∈R^{U×V}，真正的二维卷积需要把卷积核旋转 180°：

y_{ij}=Σ_{u=1}^U Σ_{v=1}^V w_{uv} x_{i-u+1,j-v+1}。

深度学习框架通常实际计算互相关，即卷积核不翻转：

y_{ij}=Σ_{u=1}^U Σ_{v=1}^V w_{uv} x_{i+u-1,j+v-1}。

> 考试先看题目是否明确要求“翻转卷积核”。若题目按 CNN/深度学习惯例给滑动窗口，通常直接逐元素相乘求和，不翻转；若严格按数学卷积定义，则先将卷积核旋转 180°。

### 输出尺寸

输入高宽 H×W，卷积核 K_h×K_w，零填充 P_h、P_w，步长 S_h、S_w，则

H_out=floor((H+2P_h-K_h)/S_h)+1；

W_out=floor((W+2P_w-K_w)/S_w)+1。

若步长 1、无填充，输出为 (H-K_h+1)×(W-K_w+1)。

### 固定答题步骤

1. 写明是否翻转卷积核，并写出实际使用的核。
2. 用输出尺寸公式确定结果矩阵大小。
3. 从左到右、从上到下移动窗口。
4. 每个位置做“窗口与卷积核逐元素相乘后求和”。
5. 若有偏置，最后每个输出元素加偏置；若有激活函数，再做激活。

### 例题（按 CNN 互相关，不翻转）

输入与卷积核：

```text
X = [[1, 2, 0, 1],        K = [[ 1, 0],
     [3, 1, 2, 2],             [-1, 1]]
     [0, 1, 3, 1],
     [2, 2, 1, 0]]
```

第一项 y_11=1×1+2×0+3×(-1)+1×1=-1。

最终输出：

```text
Y = [[-1, 3, 0],
     [ 4, 3, 0],
     [ 0, 0, 2]]
```

### 多通道补充

若输入有 C_in 个通道、输出有 C_out 个通道，则一个输出通道要对全部输入通道分别卷积后求和：

Y[:,:,c_o]=Σ_{c_i=1}^{C_in} X[:,:,c_i]⊗K[:,:,c_i,c_o]+b_{c_o}。

参数量为 K_h K_w C_in C_out + C_out。

## 2.2 概率图（两个图，10 分）

### 2.2.1 有向图：贝叶斯网络

> 贝叶斯网络用有向无环图描述变量之间的关系。每个节点对应随机变量，每条有向边表示直接依赖；联合概率等于每个节点在其父节点条件下的局部条件概率的乘积：p(x)=∏_{k=1}^K p(x_k|x_{π_k})。

读图方法：为每个节点写一项“该节点 | 它的所有父节点”；没有父节点就写边缘概率。

例：A→B，A→C，B→D，C→D，则

p(A,B,C,D)=p(A)p(B|A)p(C|A)p(D|B,C)。

### 2.2.2 无向图：马尔可夫随机场

> 无向图模型也称马尔可夫随机场，用无向图描述变量之间的概率依赖关系。一个变量在给定其邻居后，条件独立于其他所有变量。其联合概率按最大团分解为 p(x)=(1/Z)∏_{c∈C}φ_c(x_c)，其中 φ_c≥0 为最大团上的势能函数，Z 为配分函数。

若无向链 A—B—C 的最大团为 {A,B}、{B,C}，则

p(A,B,C)=(1/Z)φ_AB(A,B)φ_BC(B,C)，并有“给定 B 时 A 与 C 条件独立”。

### 2.2.3 三节点条件独立性必背

1. 链式 A→B→C：不给 B 时 A、C 一般相关；给定 B 后 A 与 C 条件独立。
2. 反向链 A←B←C：结论同上，给定中间节点 B 后两端独立。
3. 共因 A←B→C：不给共同原因 B 时两端一般相关；给定 B 后 A 与 C 条件独立。
4. 共果 A→B←C：不给共同结果 B 时 A、C 独立；给定 B 或 B 的后代后，A、C 反而相关，这称为“解释消除”。

[[FIG:probability]]

### 任意概率图的答题模板

- 第一步：区分有向图还是无向图。
- 第二步：有向图找每个节点的父节点；无向图找邻居和最大团。
- 第三步：写联合概率分解。
- 第四步：判断条件独立时检查路径是否被给定变量阻断，特别注意碰撞点 A→B←C。
- 第五步：若题目给观测节点，明确写“给定哪些变量”后再判断，不能只凭两点之间是否有边。

## 2.3 梯度下降算法五步骤排序

### 标准顺序

1. 初始化模型参数 θ（以及学习率 α、停止条件）。
2. 前向计算模型预测值 ŷ=f(x;θ)。
3. 根据真实标签 y 与预测值 ŷ 计算损失 J(θ)。
4. 对损失求参数梯度 g=∇_θJ(θ)（神经网络中由反向传播完成）。
5. 按 θ←θ-αg 更新参数；若未收敛，回到第 2 步。

速记：初始化 → 前向 → 损失 → 求梯度 → 更新。

> 若给出的五项把“判断停止条件”单独列为一步，则把它放在更新之后：未满足停止条件就继续迭代，满足则输出参数。

## 2.4 机器学习常见问题（两个小空）

最可能的两个答案：欠拟合、过拟合。

| 现象 | 判断 | 本质 | 常用处理 |
|---|---|---|---|
| 训练误差高，验证误差也高 | 欠拟合 | 模型能力不足，偏差大 | 增加特征/复杂度，训练更久，减小正则化 |
| 训练误差低，验证误差明显高 | 过拟合 | 对训练集记忆过多，方差大 | 增加数据，降低复杂度，增大正则化，早停 |

一句话：欠拟合看训练集也做不好；过拟合看训练集好、验证集差。

# 第三部分 简答题

## 3.1 生成模型与判别模型的差异（10 分）

### 可直接抄写的完整答案

> 生成模型学习输入和标签的联合概率分布 p(x,y)，通常分解为 p(y)p(x|y)。分类时利用贝叶斯公式计算 p(y|x)，再选择后验概率最大的类别；因为学习了数据如何产生，它还可以用于密度估计、生成样本、缺失变量推断等任务。典型模型有朴素贝叶斯、隐马尔可夫模型、混合高斯模型、变分自编码器等。
>
> 判别模型直接学习条件概率 p(y|x) 或决策函数 y=f(x)，重点刻画输入到输出的决策边界，而不建模 p(x)。分类时直接比较 p(y|x) 或判别函数得分。典型模型有 Logistic 回归、Softmax 回归、感知器、支持向量机以及普通分类神经网络。
>
> 二者的核心区别是建模目标不同：生成模型回答“每一类数据如何产生”，判别模型回答“给定 x 应判为哪一类”。生成模型可以利用联合分布完成生成和隐变量推断，但模型假设错误会影响分类；判别模型通常对预测任务更直接、需要估计的分布更少，但一般不能直接生成样本。

### 公式对照

生成模型：先估计 p(x,y)=p(y)p(x|y)，再用

p(y|x)=p(x|y)p(y)/p(x)，ŷ=argmax_y p(x|y)p(y)。

判别模型：直接估计 p(y|x) 或 f(x)，

ŷ=argmax_y p(y|x) 或 ŷ=sign(f(x))。

### 教材中的直接例子

Logistic 回归把 x 当作确定的输入，只建模 p(y|x)，所以是判别模型；Sigmoid 信念网络把 x、y 都作为随机变量并建模联合概率 p(x,y)，所以是生成模型。

### 评分表式比较

| 比较维度 | 生成模型 | 判别模型 |
|---|---|---|
| 建模目标 | 联合分布 p(x,y) 或 p(y)p(x\|y) | 条件分布 p(y\|x) 或决策函数 f(x) |
| 主要问题 | 数据怎样生成 | 决策边界在哪里 |
| 预测方式 | 贝叶斯公式转成后验再分类 | 直接输出类别概率或得分 |
| 附加能力 | 可生成、密度估计、隐变量/缺失值推断 | 以分类或回归预测为主 |
| 典型模型 | 朴素贝叶斯、HMM、GMM、VAE | Logistic、Softmax、感知器、SVM |

## 3.2 训练单层感知器的计算过程（20 分）

### 3.2.1 模型和判错条件

将偏置写开时，单层感知器为

ŷ=sgn(w^T x+b)，y∈{+1,-1}。

样本分类正确的条件是 y(w^T x+b)>0；若 y(w^T x+b)≤0，则该样本被分错或恰在决策边界上，需要更新。

### 3.2.2 损失和更新

感知器损失：L(w;x,y)=max(0,-y(w^T x+b))。

对误分类样本，学习率为 η 时：

w←w+ηyx，b←b+ηy。

教材使用增广向量把 b 合并进 w，并在 η=1 时写成 w←w+yx。

### 3.2.3 可直接抄写的算法

> 给定训练集 D={(x^(n),y^(n))}_{n=1}^N、学习率 η 和最大迭代次数 T。首先初始化 w=0、b=0；每轮将训练样本按给定顺序或随机顺序遍历。对每个样本计算判别值 s=w^T x+b 和符号间隔 m=ys。若 m≤0，则按 w←w+ηyx、b←b+ηy 更新；若 m>0，则参数不变。重复遍历，直到一整轮没有误分类样本或达到最大迭代次数。最终决策边界为 w^T x+b=0。

### 3.2.4 手算例题

训练样本依次为：x_1=(2,1), y_1=+1；x_2=(-2,1), y_2=+1；x_3=(-1,-2), y_3=-1。取 η=1，初始 w=(0,0), b=0。

| 样本 | 更新前 s=w^T x+b | ys | 判断 | 更新后参数 |
|---|---:|---:|---|---|
| x_1 | 0 | 0 | ys≤0，更新 | w=(2,1), b=1 |
| x_2 | -2 | -2 | ys≤0，更新 | w=(0,2), b=2 |
| x_3 | -2 | 2 | ys>0，正确 | 参数不变 |

最后检查：

- 对 x_1：s=0×2+2×1+2=4>0，预测 +1；
- 对 x_2：s=0×(-2)+2×1+2=4>0，预测 +1；
- 对 x_3：s=0×(-1)+2×(-2)+2=-2<0，预测 -1。

因此一轮后全部分类正确，决策边界为 2x_2+2=0，即 x_2=-1。

### 3.2.5 易错点

- 标签必须使用 ±1；若题目给 0/1，先把 0 转成 -1。
- 判错判断用 y(w^T x+b)≤0，不是只看 w^T x+b≤0。
- 更新时权重和偏置都要更新；也可用增广 x←[x;1] 合并写一次。
- 每次参数更新后，后续样本必须使用新参数。
- 只有线性可分数据能保证有限次更新后收敛；不可分数据要设置最大迭代次数。

# 第四部分 编程题：一个程序覆盖四项内容（30 分）

## 4.1 问题建模

课程练习给出 N 个一维样本 {(x_n,y_n)}，希望在不知道真实函数 f(·) 的情况下，用线性回归拟合 y=f(x)。“线性”是指模型对参数 w 线性，不要求对原始输入 x 线性。先用非线性基函数把 x 映射成特征 φ(x)，再做线性组合：

ŷ(x)=w_0+Σ_{j=1}^M w_j φ_j(x)=w^T φ_hat(x)。

其中 φ_hat(x)=[1,φ_1(x),…,φ_M(x)]^T，第一个 1 用来学习偏置。

## 4.2 两种基函数

### 多项式基函数

φ_j(x)=x^j，j=1,…,M。

设计向量为 [1,x,x^2,…,x^M]。次数太低可能欠拟合，次数太高容易过拟合并产生数值不稳定。代码中应先把 x 缩放到 [-1,1] 再求幂。

### 高斯基函数

φ_j(x)=exp(-(x-μ_j)^2/(2σ^2))，j=1,…,M。

μ_j 是第 j 个高斯中心，可在训练集 x 的最小值与最大值之间均匀放置；σ 控制高斯宽度，常取相邻中心间距。每个基函数只在中心附近响应，适合拟合局部变化。

### 关键数据泄漏规则

最小值、最大值、中心 μ_j、宽度 σ 都只能由训练集确定；测试集只能调用相同的变换，不能重新 fit。

## 4.3 设计矩阵与教材记号

代码通常令每行是一个样本，得到 Φ∈R^{N×(M+1)}：

```text
Phi = [[1, φ_1(x_1), ..., φ_M(x_1)],
       [1, φ_1(x_2), ..., φ_M(x_2)],
       ...,
       [1, φ_1(x_N), ..., φ_M(x_N)]]
```

预测向量为 ŷ=Φw。

教材第 2.3 节令样本按列组成 X，因此写成 w*=(XX^T)^(-1)Xy；代码令样本按行组成 Φ，所以等价地写成 w*=(Φ^TΦ)^(-1)Φ^Ty。两式只是矩阵方向约定不同。

## 4.4 最小二乘法

目标函数取

J(w)=1/2 ||y-Φw||_2^2。

梯度为

∇_wJ(w)=Φ^T(Φw-y)。

令梯度为 0，得到正规方程

Φ^TΦw=Φ^Ty，

所以

w*=(Φ^TΦ)^(-1)Φ^Ty。

若 Φ^TΦ 不可逆，应使用伪逆 `pinv`，不要直接调用 `inv`：

```python
w = np.linalg.pinv(phi.T @ phi) @ phi.T @ y
```

## 4.5 批量梯度下降

若把平均平方损失写为

J(w)=1/(2N)||Φw-y||_2^2，

则梯度为

∇_wJ(w)=1/N Φ^T(Φw-y)，

更新公式为

w←w-α/N Φ^T(Φw-y)=w+α/N Φ^T(y-Φw)。

这与教材公式 (2.42) 的方向一致。梯度下降不要求显式求逆，但学习率过大可能发散，过小则收敛慢。

## 4.6 考场精简代码（建议优先记忆）

```python
import numpy as np

def polynomial_basis(x, M, xmin, xmax):
    x = np.asarray(x).reshape(-1, 1)
    z = 2 * (x - xmin) / max(xmax - xmin, 1e-12) - 1
    return z ** np.arange(1, M + 1).reshape(1, -1)

def gaussian_basis(x, M, xmin, xmax):
    x = np.asarray(x).reshape(-1, 1)
    mu = np.linspace(xmin, xmax, M).reshape(1, -1)
    sigma = max((xmax - xmin) / max(M - 1, 1), 1e-12)
    return np.exp(-((x - mu) ** 2) / (2 * sigma ** 2))

def make_phi(x, basis, M, xmin, xmax):
    if basis == 'polynomial':
        feat = polynomial_basis(x, M, xmin, xmax)
    else:
        feat = gaussian_basis(x, M, xmin, xmax)
    return np.column_stack([np.ones(len(x)), feat])

def least_squares(phi, y):
    return np.linalg.pinv(phi.T @ phi) @ phi.T @ y

def gradient_descent(phi, y, lr=0.05, epochs=100000):
    w = np.zeros(phi.shape[1])
    N = len(y)
    for _ in range(epochs):
        error = phi @ w - y
        grad = phi.T @ error / N
        w -= lr * grad
    return w

# 训练：范围只能从训练集取得
xmin, xmax = x_train.min(), x_train.max()
phi_train = make_phi(x_train, 'gaussian', 10, xmin, xmax)
phi_test  = make_phi(x_test,  'gaussian', 10, xmin, xmax)

# 二选一；考试若要求比较，就分别运行
w = least_squares(phi_train, y_train)
# w = gradient_descent(phi_train, y_train)

y_pred = phi_test @ w
rmse = np.sqrt(np.mean((y_test - y_pred) ** 2))
print('RMSE =', rmse)
```

## 4.7 四种组合怎么写

| 组合 | 只需要修改 |
|---|---|
| 多项式 + 最小二乘 | `basis='polynomial'`，调用 `least_squares` |
| 多项式 + 梯度下降 | `basis='polynomial'`，调用 `gradient_descent` |
| 高斯 + 最小二乘 | `basis='gaussian'`，调用 `least_squares` |
| 高斯 + 梯度下降 | `basis='gaussian'`，调用 `gradient_descent` |

## 4.8 编程题常见失分点

1. 忘记在设计矩阵第一列加入 1，导致没有偏置项。
2. `x` 形状为 `(N,)`，直接和 `(M,)` 运算产生错误广播；应先 reshape 为 `(N,1)`。
3. 把矩阵乘法 `@` 写成逐元素乘法 `*`。
4. 正规方程转置方向写错；代码中样本按行时必须是 `Phi.T @ Phi`。
5. 直接 `inv(Phi.T@Phi)`，遇到奇异矩阵报错；应使用 `pinv`。
6. 梯度漏掉 `Phi.T`，正确形状应与 w 相同。
7. 梯度下降符号写反；应沿负梯度方向更新。
8. 多项式直接用 0–25 的高次幂，数值迅速变大；先缩放到 [-1,1]。
9. 用测试集计算缩放范围或高斯中心，造成数据泄漏。
10. 评价“标准差”实际通常使用 RMSE：sqrt(mean((y-y_pred)^2))。

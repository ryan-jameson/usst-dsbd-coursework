# 神经网络与深度学习

上海理工大学（经管实验班—数据科学与大数据技术专业）课程学习资料。

线性模型、CNN、RNN、注意力机制、强化学习及课程笔记。

本目录收录 153 个代码/笔记文件、15 份文档文字版。

## 使用说明

代码和笔记见 [code/](code/)（若有）。请先查找项目自己的 README、requirements.txt、package.json 或构建文件；运行环境、数据集、模型权重和账号配置需按项目说明准备。此处不承诺全部旧代码在当前环境直接运行。

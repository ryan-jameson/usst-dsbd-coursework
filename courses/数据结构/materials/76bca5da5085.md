## 原幻灯片 11

时间复杂度通常用“大O”来表示。
②   时间复杂度
“O”的形式定义为：
    当且仅当存在正整数c和N，使得对所有的n≥N，有|T(n)|≤c|f(n)|成立，则称T(n)是O(f(n))，记为T(n)=O(f(n))    
           
 【示例】   
          T(n) = 2n2+2n+1= O(n2)
只求出T(n)的最高阶，忽略其低阶项和常系数。

## 原幻灯片 16

一个没有循环的算法的执行时间与问题规模n无关，记作O(1)，也称作常数阶。
一个只有一重循环的算法的执行时间与问题规模n的增长呈线性增大关系，记作O(n)，也称线性阶。
其余常用的算法时间复杂度还有平方阶O(n2)、立方阶O(n3)、对数阶O(log2n)、指数阶O(2n)等。
一般地：
各种不同算法时间复杂度的比较关系如下：              
     O(1)<O(log2n)<O(n)<O(nlog2n)<O(n2)<O(n3)<O(2n)<O(n!)

## 原幻灯片 20

  设计存储结构
采用一个整型数组存放集合的元素。
由于C/C++语言中数组并没有一个标识数组中实际元素个数的值，为此用一个整型变量length表示数组中的实际元素个数。
设计集合类型Set如下：
typedef struct		//集合结构体类型
{  int data[MaxSize];	//存放集合中的元素，其中MaxSize为常量
   int length;		//存放集合中实际元素个数
} Set;			//将集合结构体类型用一个新类型名Set表示

## 原幻灯片 21

  设计运算算法

void cset(Set &s,int a[],int n)  //由数组a创建集合s
{  for (int i=0;i<n;i++)
      s.data[i]=a[i];
   s.length=n;
}

## 原幻灯片 22

  设计运算算法

void dispset(Set s)		//输出集合s中的所有元素
{  for (int i=0;i<s.length;i++)
      printf("%d ",s.data[i]);
   printf("\n");
}
int inset(Set s,int e)	//判断e是否在集合s中
{  for (int i=0;i<s.length;i++)
     if (s.data[i]==e)
         return 1;
   return 0;
}

## 原幻灯片 25

  时间复杂度的估算规则
1）时间复杂度分为最好、最坏和平均
    时间复杂度由算法的规模、输入和算法本身决定的
2）元操作只需要1个单位（元操作：赋值、比较、算术运算、逻辑运算等）
3）控制语句：      （1）if（  c）s1 else s2
                      C 的执行时间+s1和s2执行时间最长的
                  （2）case语句
                        执行时间最长的语句块
                  （3）for循环语句
                      执行循环体所需要的时间乘以循环次数
                  （4）while( c )循环语句
          计算条件表达式C需要的时间与执行循环体需要的时间之和乘以循环的次数
 4）函数调用
            控制转移和执行函数本身

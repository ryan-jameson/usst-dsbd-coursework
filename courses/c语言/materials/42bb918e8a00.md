简介
项目背景
在数字化浪潮的推动下，我们致力于开发一款集图书管理、售卖于一体的智能系统，旨在提升书店的运营效率，优化读者的购书体验，促进图书文化的传承与共享。
本系统采用c语言编程，实现了图书信息的全面数字化管理。通过构建完善的图书信息链表，系统能够实时追踪图书的库存状态、销售情况等，为书店管理者提供精准的数据支持，助力决策优化。
在售卖方面，系统支持读者随时随地完成购书操作。同时，系统能够允许读者收藏或搜索喜爱的书籍，提升购书满意度和购买转化率。
此外，本系统还注重用户体验的提升。通过简洁明了的界面设计、流畅的操作流程以及个性化的服务设置，让每一位读者都能享受到便捷、愉悦的购书过程。同时，系统还提供了丰富的互动功能，如读者评论、评分、分享等，促进读者之间的交流与分享，增强社区氛围。
更重要的创新点在于通过设置类操作限制客户和管理员的权限操作，使得权限分明，提升系统的数据安全性与管理员的操作可靠性，允许管理员进行用户权限设置、账户注销、书籍删减等操作；设置密码校验操作，优化服务流程，使得系统更加人性化。

作品特色
5.1 特色功能
5.1.1 字体印刷程序
我们想通过字体染色优化用户体验，以强调用户操作的正确与否，所以我们将系统指引定义为紫色输出，错误操作为红色输出，正确操作为绿色输出，用来强调输出结果，使得程序输出更加可视化和美观。
5.1.2 权限管理功能
管理员除了可以增减仓库书籍以外，还能进入全新的权限管理界面，注销用户信息、增减管理员账号、查看用户密码等等操作，优化管理员权限，同时更加方便系统管理员分配工作，每次更改账户后实时通过链表输出，管理员可以随时查看自己的操作结果并保存数据。
5.1.3 购物车功能
我们单独给购物车管理设计了一个界面，通过购物车用户随时可以查看自己的收藏书籍以及更加方便删减书本和结账等操作，每次删减完实时通过链表输出，用户可以随时查看自己的操作结果并保存数据或结账。
5.1.4 用户level
我们为了区分管理员账户和客户账户的分类，设计了一个user.level计数，如果检测为管理员账号则为level=1，用户账号或注册则level=-1，优先从管理员账号登录，可以从管理员界面进入用户界面，这样我们自然通过UISwitch（）函数自然导入到了客户ui或管理员ui，也区分了两种账户的不同操作。
5.2 攻克难点
5.2.1 链表频繁遍历
每一次查找、删除、检索防止重复都是需要以查找到该结点为前提的，因此每次这种函数都需要写一遍链表从头文件开始遍历整个链表来检索特定结点，因此我们设计了一个函数，输出特定结点，通过输出特定结点来确定是否查找成功或删除之前是否找到相关结点或是否添加时是否找到重复结点。
而这也带来一个问题，删除时我们也需要前一个结点与待删除节点的后一个结点进行连接，单链表的载入又不能回撤，只能从头到尾，因此如果只是输出查找的结点那么在遇到删除问题时还需要再遍历一遍链表，为了减便这种操作，我们可以通过查找函数输出前一个结点，从而能通过该结点的next找到目标结点的同时更方便删除时将前一个结点与后一个结点接入。
5.2.2 频繁以用户名查找
我们设计了一个数据文档存储所有用户的心仪书本，在前面标注用户名以确定特定用户喜好，使得我们的文件操作可以集中于一个文件，但是输出链表为了更有针对性的找到特定用户的购物车，我们通过操作单独将个人购物车链表分离出来，防止我们输出整个用户购物车链表时要频繁输入特定用户名查找个人购物车链表，最后保存数据时将操作完毕的个人购物车链表导入全体购物车链表，再将全体购物车链表复写到文件当中即可。
5.2.3 UI繁杂
为了优化用户操作，我们不想进入新的ui时还出现前一个ui操作，因此写入system（“cls”）语句，在每一次进入新界面或进入新操作时刷新整个输出界面，使得用户操作更加美观，更符合正常的用户操作。
5.2.4 输出内容过快消失
进入新的界面后，登录成功或失败的提示会快速消失，导致用户难以判断是否登录成功或其他指示，我们在每一个界面跳转时设置了sleep函数，设置界面停留时间使得用户能更轻松查看界面操作提示，提升界面操作方便性。

总结
在编写程序的时候，我们通过网络查阅学习学会了课本上难以学到的知识，虽然最后成功运行了代码，但是我们还是深知自己的代码之路依旧漫长如故，与其他优秀的项目始终有着极大的差距，运行成功是一种成就，是自己在学习路上的一个成功的印记与证明，但同时也为自己未来的学习指明了方向，我们发现自己还有许多知识未涉及到，目前所学的内容依旧十分肤浅，还是无法支持自己写成一个成功的项目的，希望在未来能通过学习弥补这种鸿沟。
而关于项目，目前依旧存在关于界面无法准确回退到原有界面的问题，这不符合大部分用户的操作习惯，同时在处理大量数据输入时程序容易出现卡顿退出现象，结账后库存文件不能实时清理只能通过保存数据实现文件更新，希望未来有时间能更加精进自己的知识技能，将代码更简化，写的能更加优雅，逻辑更加清晰，同时操作更加考虑到普遍用户的正常习惯等等，道阻且长，未来还需继续努力。
我们会牢记程序运行成功带来的喜悦和头脑风暴时带来的痛苦，这种悲喜交织才彰显着我们学习路上的步步精进，也组成了我们成长的心路历程。

        clientlog(C);
        adminlog(A);
        if(checklog(name,password,A)){
            _islogin=true;
            ui.level=1;
            strcpy(ui.username,name);
            Sleep(1000);
    return printGreen("   Successfully login\n");
        }else{

            strcpy(ui.username,name);

            Sleep(1000);
            return printGreen("   Successfully login\n");

i++;//设置三次输入密码限制  
}

Sleep(1000);
        printRed("已超过登录次数限制\n");

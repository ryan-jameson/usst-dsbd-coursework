## 1. 抽样估计

### 1.1 出租车连续编号估计

**题目：**  
某城市出租车牌号从 `0101` 开始连续发放。随机观察到 10 辆出租车牌号：

`0421, 0128, 0702, 0410, 0598, 0674, 0712, 0529, 0867, 0312`

估计该城市出租车总数，并说明为什么不能直接把最大牌号当作总量。

**答案解析：**

1. 把牌号转成从 1 开始的连续序号。若 `0101` 是第 1 辆，则 `0867` 对应序号为 `m=867-100=767`。
2. 样本数 `n=10`，最大观察序号 `m=767`。
3. 连续编号抽样常用估计为：

   ```text
   N_hat = (n+1)m/n - 1
   ```

4. 代入得：

   ```text
   N_hat = 11*767/10 - 1 = 842.7
   ```

5. 因此估计出租车总数约为 `843` 辆，对应最大牌号约为 `0943`。
6. 不能直接取 `767`，因为随机样本中的最大编号通常小于真实最大编号；估计公式是在样本最大值基础上补偿“没有抽到的尾部”。

### 1.2 德国坦克问题的下界与估计值

**题目：**  
某批设备编号从 1 到 `N` 连续发放。随机抽到 8 台，编号为：

`18, 31, 44, 55, 80, 96, 117, 124`

回答：

1. `N` 的最小可能值是多少？
2. 用连续编号抽样公式估计 `N`。
3. 解释“最小可能值”和“估计值”的区别。

**答案解析：**

1. 样本最大编号是 `m=124`，所以总数至少为 `124`。
2. 样本数 `n=8`，估计公式为：

   ```text
   N_hat = (n+1)m/n - 1
   ```

3. 代入得：

   ```text
   N_hat = 9*124/8 - 1 = 138.5
   ```

4. 整数化后可估计为约 `139` 台。
5. `124` 是确定下界，因为已经观察到第 124 号；`139` 是统计估计，因为考虑到真实最大编号大概率比样本最大编号更大。

## 2. 线性规划：敏感性分析、影子价格

### 2.1 奶制品生产计划 LP

**题目：**  
某奶制品厂每天有 50 桶牛奶和 480 小时工时。1 桶牛奶生产 A1 需要 12 小时，可得 3 kg A1，利润 24 元/kg；1 桶牛奶生产 A2 需要 8 小时，可得 4 kg A2，利润 16 元/kg。A1 每天最多加工 100 kg。

建立线性规划模型，并求最优生产计划和最大利润。

**答案解析：**

1. 设 `x1` 为用于生产 A1 的牛奶桶数，`x2` 为用于生产 A2 的牛奶桶数。
2. 每桶 A1 利润为 `24*3=72` 元，每桶 A2 利润为 `16*4=64` 元。
3. 模型为：

   ```text
   max z = 72x1 + 64x2
   s.t. x1 + x2 <= 50
        12x1 + 8x2 <= 480
        3x1 <= 100
        x1, x2 >= 0
   ```

4. 最优解在紧约束 `x1+x2=50` 与 `12x1+8x2=480` 的交点。
5. 解得：

   ```text
   x1 = 20, x2 = 30
   z = 72*20 + 64*30 = 3360
   ```

6. 最优方案是用 20 桶牛奶生产 A1、30 桶生产 A2，最大利润为 `3360` 元。
7. A1 加工量为 `3*20=60 kg`，低于 100 kg，因此 A1 加工能力约束不是紧约束。

### 2.2 影子价格与敏感性判断

**题目：**  
沿用上题。PPT 给出的影子价格为：牛奶 48 元/桶，工时 2 元/小时，A1 加工能力 0 元/kg。A1 的目标函数系数允许范围为 `(64,96)`。

回答：

1. 若额外 1 桶牛奶售价 35 元，应不应该买？
2. 临时工最高每小时可付多少钱？
3. 若 A1 利润从 24 元/kg 上升到 30 元/kg，原生产计划是否改变？

**答案解析：**

1. 牛奶影子价格为 `48` 元/桶，表示在当前最优结构不变的范围内，多 1 桶牛奶最多可多赚 48 元。
2. 额外牛奶售价为 35 元，且 `35<48`，所以应购买。
3. 工时影子价格为 `2` 元/小时，所以临时工最高可付 `2` 元/小时；超过 2 元就不划算。
4. A1 原来每桶利润系数为 `24*3=72`。
5. A1 利润升至 30 元/kg 后，每桶利润系数变为 `30*3=90`。
6. 因为 `90` 落在允许范围 `(64,96)` 内，所以最优基不变，生产计划仍为 `x1=20,x2=30`。
7. A1 加工能力影子价格为 0，说明当前多给 A1 加工能力不能提高利润，因为 A1 加工能力本来就没有用满。

## 3. 库存目标函数建模

### 3.1 最优生产周期

**题目：**  
某产品日需求量 `r=100` 件。每次生产准备费 `c1=5000` 元，每天每件库存费 `c2=1` 元，生产时间忽略。问多少天生产一次、每次生产多少件，使平均每天总费用最小？

**答案解析：**

1. 设 `T` 天生产一次，每次生产 `Q` 件。
2. 刚好满足需求时：

   ```text
   Q = rT
   ```

3. 每天平均准备费为：

   ```text
   c1/T
   ```

4. 库存从 `Q` 线性下降到 0，平均库存为 `Q/2=rT/2`，所以每天平均库存费为：

   ```text
   c2*r*T/2
   ```

5. 平均每天费用函数为：

   ```text
   C(T) = c1/T + c2*r*T/2
   ```

6. 求导并令其为 0：

   ```text
   C'(T) = -c1/T^2 + c2*r/2 = 0
   T* = sqrt(2c1/(c2*r))
   ```

7. 代入 `c1=5000,c2=1,r=100`：

   ```text
   T* = sqrt(10000/100) = 10
   Q* = 100*10 = 1000
   ```

8. 最优方案是每 `10` 天生产一次，每次生产 `1000` 件。

### 3.2 带仓库容量约束的库存模型

**题目：**  
某产品日需求量 `r=80` 件，每次准备费 `c1=3200` 元，每天每件库存费 `c2=0.8` 元。仓库最多存放 600 件。求最优生产周期和批量。

**答案解析：**

1. 不考虑仓库容量时：

   ```text
   T* = sqrt(2c1/(c2*r))
      = sqrt(6400/(0.8*80))
      = sqrt(100)
      = 10
   ```

2. 对应批量为：

   ```text
   Q* = rT* = 80*10 = 800
   ```

3. 但仓库最多存放 600 件，所以必须满足：

   ```text
   Q = 80T <= 600
   T <= 7.5
   ```

4. 无约束最优周期 `10` 天超过容量允许的 `7.5` 天，因此不可行。
5. 在 `T<=7.5` 范围内，费用函数为：

   ```text
   C(T)=3200/T+0.8*80*T/2=3200/T+32T
   ```

6. 因为无约束最优点在 10 天，且当前可行区间在其左侧，费用随 `T` 增大而下降，所以取最大可行周期：

   ```text
   T = 7.5, Q = 600
   ```

7. 若考试要求整数天，可比较 `T=7` 与 `T=8`，但 `T=8` 会使 `Q=640` 超过仓库容量，所以选 `T=7` 天附近的可行方案。

## 4. 0-1 规划

### 4.1 逻辑命题线性化

**题目：**  
设 `x1,x2` 都是 0-1 变量。分别写出下列约束：

1. 选甲必须选乙。
2. 选甲就不能选乙。
3. 甲乙至多选一个。
4. 甲乙至少选一个。
5. 甲乙恰好选一个。

**答案解析：**

1. 选甲必须选乙：

   ```text
   x1 <= x2
   ```

2. 选甲就不能选乙：

   ```text
   x1 + x2 <= 1
   ```

3. 甲乙至多选一个：

   ```text
   x1 + x2 <= 1
   ```

4. 甲乙至少选一个：

   ```text
   x1 + x2 >= 1
   ```

5. 甲乙恰好选一个：

   ```text
   x1 + x2 = 1
   ```

6. 记忆方法：`x=>y` 写 `x<=y`；互斥写和不超过 1；至少选写和不小于 1。

### 4.2 项目选择 0-1 规划

**题目：**  
有 5 个项目，数据如下：

| 项目 | 类别 | 成本 | 收益 | 依赖 |
|---:|---|---:|---:|---|
| 1 | 生产 | 4 | 8 | 无 |
| 2 | 化工 | 3 | 6 | 无 |
| 3 | 生产 | 3 | 7 | 必须先选 1 |
| 4 | 数字 | 2 | 5 | 无 |
| 5 | 数字 | 2 | 4 | 必须先选 2 |

预算不超过 9，且至少选 1 个生产项目、1 个化工项目、1 个数字项目。建立 0-1 规划并求最优选择。

**答案解析：**

1. 设 `xi=1` 表示选择项目 `i`，否则为 0。
2. 目标函数：

   ```text
   max 8x1+6x2+7x3+5x4+4x5
   ```

3. 预算约束：

   ```text
   4x1+3x2+3x3+2x4+2x5 <= 9
   ```

4. 类别约束：

   ```text
   x1+x3 >= 1       生产
   x2 >= 1          化工
   x4+x5 >= 1       数字
   ```

5. 依赖约束：

   ```text
   x3 <= x1
   x5 <= x2
   ```

6. 因为必须选化工，所以 `x2=1`。必须选生产和数字。
7. 可行组合中：

   ```text
   {1,2,4}: 成本 4+3+2=9，收益 8+6+5=19
   {1,2,5}: 成本 4+3+2=9，收益 8+6+4=18
   ```

8. 含项目 3 的组合因依赖项目 1 且还要选项目 2 与数字项目，会超过预算或不满足类别要求。
9. 最优选择为项目 `1,2,4`，最大收益为 `19`。

## 5. Logistic

### 5.1 Logistic 捕捞的最大持续产量

**题目：**  
无捕捞时鱼量 `x` 满足：

```text
dx/dt = r x(1-x/N)
```

捕捞量与鱼量成正比，`h(x)=Ex`。求使持续产量最大的捕捞强度 `E`、稳定鱼量 `x` 和最大持续产量。

**答案解析：**

1. 有捕捞时模型为：

   ```text
   dx/dt = r x(1-x/N) - Ex
   ```

2. 持续捕捞要求鱼量稳定，即 `dx/dt=0`。
3. 非零平衡点满足：

   ```text
   r(1-x/N)=E
   x=N(1-E/r)
   ```

4. 持续产量为：

   ```text
   h(E)=Ex=EN(1-E/r)
   ```

5. 对 `E` 求导：

   ```text
   h'(E)=N(1-2E/r)
   ```

6. 令 `h'(E)=0`，得：

   ```text
   E*=r/2
   x*=N/2
   hmax=rN/4
   ```

7. 记忆：最大持续产量发生在鱼量保留为环境容量的一半时。

### 5.2 给定捕捞强度下的稳定鱼量

**题目：**  
某渔场环境容量 `N=1000` 吨，自然增长率 `r=0.6`。若捕捞强度 `E=0.2`，求正平衡鱼量和持续产量，并判断是否达到最大持续产量。

**答案解析：**

1. 正平衡鱼量：

   ```text
   x = N(1-E/r)
     = 1000*(1-0.2/0.6)
     = 666.7
   ```

2. 持续产量：

   ```text
   h = Ex = 0.2*666.7 = 133.3
   ```

3. 最大持续产量对应：

   ```text
   E*=r/2=0.3
   x*=N/2=500
   hmax=rN/4=0.6*1000/4=150
   ```

4. 当前 `E=0.2` 小于 `0.3`，鱼量保留较多，持续产量 `133.3` 小于最大持续产量 `150`。
5. 若题目强调生态保护，`E=0.2` 可能更稳妥；若只问产量最大，则应取 `E=0.3`。

## 6. 决策图映射

### 6.1 商人过河的状态与决策

**题目：**  
三名商人各带一名随从过河，船每次最多坐两人。任一岸只要商人数不为 0 且随从多于商人，就不安全。用状态和决策表示该问题，并给出一个可行过河方案。

**答案解析：**

1. 用状态 `s=(x,y)` 表示此岸商人数 `x`、随从数 `y`。
2. 初始状态为 `(3,3)`，目标状态为 `(0,0)`。
3. 容许状态为：

   ```text
   S={(3,y),(0,y), y=0,1,2,3} U {(1,1),(2,2)}
   ```

4. 决策 `d=(u,v)` 表示船上有 `u` 名商人、`v` 名随从，且：

   ```text
   1 <= u+v <= 2
   ```

5. 船从此岸到彼岸时状态减少 `d`，船返回时状态增加 `d`。
6. 一个可行方案为：

   ```text
   CC 去，C 回；
   CC 去，C 回；
   MM 去，MC 回；
   MM 去，C 回；
   CC 去，C 回；
   CC 去。
   ```

7. 对应状态序列：

   ```text
   (3,3)->(3,1)->(3,2)->(3,0)->(3,1)->(1,1)
   ->(2,2)->(0,2)->(0,3)->(0,1)->(0,2)->(0,0)
   ```

8. 每个状态都在容许状态集合中，所以方案合法。

### 6.2 把过河过程画成决策图

**题目：**  
把上题中的可行方案看成决策图。说明图中的“节点”“有向边”“边标签”分别是什么，并写出前 4 条边的标签。

**答案解析：**

1. 节点是状态，例如 `(3,3)`、`(3,1)`、`(3,2)`。
2. 有向边表示一次乘船后的状态转移。
3. 边标签是决策 `d=(u,v)`，即本次船上商人数和随从数。
4. 若 `M` 表示商人、`C` 表示随从，前 4 条边为：

   ```text
   (3,3)->(3,1): CC 去，d=(0,2)
   (3,1)->(3,2): C 回，d=(0,1)
   (3,2)->(3,0): CC 去，d=(0,2)
   (3,0)->(3,1): C 回，d=(0,1)
   ```

5. 决策图的作用是把“讲故事式步骤”转成“状态节点 + 合法转移边”。考试中只要节点都合法、边都满足船容量，就能系统检查方案是否正确。

## 7. 席位分配与投票

### 7.1 Hamilton 法与 EP 法

**题目：**  
三州人口分别为甲 `103`、乙 `63`、丙 `34`，总人口 200。分别用 Hamilton 法分配 20 席和 21 席，并说明 Hamilton 法的问题。再用 EP 法判断 21 席时第 20、21 席应给谁。

**答案解析：**

1. Hamilton 法公式：

   ```text
   q_i = N p_i / P
   ```

2. 20 席时份额为：

   ```text
   甲 10.3，乙 6.3，丙 3.4
   ```

3. 先给整数部分 `10,6,3`，还剩 1 席，最大余数是丙 `0.4`，所以结果为：

   ```text
   10, 6, 4
   ```

4. 21 席时份额为：

   ```text
   甲 10.815，乙 6.615，丙 3.570
   ```

5. 先给 `10,6,3`，还剩 2 席，余数最大的两个是甲和乙，所以结果为：

   ```text
   11, 7, 3
   ```

6. 问题：总席位从 20 增至 21，丙州反而从 4 席变成 3 席，这就是 Hamilton 悖论。
7. EP 法用优先值：

   ```text
   Q_i = p_i/sqrt(n_i(n_i+1))
   ```

8. 从 `10,6,3` 开始，第 20 席比较后给甲；变成 `11,6,3` 后，第 21 席比较后给丙。
9. EP 法 21 席结果为：

   ```text
   11, 6, 4
   ```

### 7.2 同一组选票下不同投票规则

**题目：**  
30 名学生对 A、B、C、D 四个方案排序投票，偏好如下：

| 人数 | 排序 |
|---:|---|
| 9 | A > D > C > B |
| 10 | C > D > A > B |
| 11 | B > D > C > A |

分别用简单多数法、单轮决胜法、Coombs 法和 Borda 法判断获胜者。

**答案解析：**

1. 简单多数法只看第一名票：

   ```text
   A:9, B:11, C:10, D:0
   ```

   所以 B 获胜。

2. 单轮决胜法取第一名票最多的 B 和 C 进入决胜。9 个 A 组选民更偏向 C，10 个 C 组选民选 C，11 个 B 组选民选 B，所以 C 以 `19:11` 获胜。
3. Coombs 法每轮淘汰倒数第一最多者。第一轮 B 被 19 人排最后，先淘汰 B；之后 A 被淘汰；最后 D 对 C，D 获胜。
4. Borda 法给第 1、2、3、4 名分别 `4,3,2,1` 分：

   ```text
   A = 9*4 + 10*2 + 11*1 = 67
   B = 11*4 + 19*1 = 63
   C = 10*4 + 20*2 = 80
   D = 30*3 = 90
   ```

5. Borda 法 D 获胜。
6. 结论：同一批偏好，因规则使用的信息不同，会得出不同获胜者。考试要先写清规则，再算结果。

## 8. 决策矩阵与 TOPSIS

### 8.1 汽车选购的决策矩阵与 SAW

**题目：**  
三辆车 A1、A2、A3 的属性如下：

| 方案 | 价格/万元 | 性能 | 款式 |
|---|---:|---:|---:|
| A1 | 25 | 9 | 7 |
| A2 | 18 | 7 | 7 |
| A3 | 12 | 5 | 5 |

价格为费用型，性能和款式为效益型。已知权重 `w=(0.5330,0.3293,0.1377)`。用“价格取倒数后最大化标准化”的 SAW 法排序。

**答案解析：**

1. 决策矩阵行为方案、列为属性。
2. 价格是费用型，可先取倒数，再做最大化标准化。价格标准化约为：

   ```text
   A1: (1/25)/(1/12)=0.4800
   A2: (1/18)/(1/12)=0.6667
   A3: 1.0000
   ```

3. 性能按最大值 9 标准化：

   ```text
   A1:1.0000, A2:0.7778, A3:0.5556
   ```

4. 款式按最大值 7 标准化：

   ```text
   A1:1.0000, A2:1.0000, A3:0.7143
   ```

5. SAW 综合值：

   ```text
   V1 = 0.5330*0.4800 + 0.3293*1 + 0.1377*1 = 0.7228
   V2 = 0.5330*0.6667 + 0.3293*0.7778 + 0.1377*1 = 0.7492
   V3 = 0.5330*1 + 0.3293*0.5556 + 0.1377*0.7143 = 0.8143
   ```

6. 排序为：

   ```text
   A3 > A2 > A1
   ```

7. 原因是价格权重最大，而 A3 的价格优势很强。

### 8.2 TOPSIS 相对接近度

**题目：**  
汽车选购例中，PPT 给出 TOPSIS 距离：

```text
S+ = (0.2141, 0.1470, 0.1087)
S- = (0.1087, 0.0966, 0.2141)
```

计算三个方案的相对接近度并排序。

**答案解析：**

1. TOPSIS 接近度公式为：

   ```text
   C_i = S_i^-/(S_i^+ + S_i^-)
   ```

2. 逐项计算：

   ```text
   C1 = 0.1087/(0.2141+0.1087) = 0.3367
   C2 = 0.0966/(0.1470+0.0966) = 0.3966
   C3 = 0.2141/(0.1087+0.2141) = 0.6633
   ```

3. `C_i` 越大越好，所以排序为：

   ```text
   A3 > A2 > A1
   ```

4. 解释：好方案应离正理想解近、离负理想解远。A3 的 `S+` 最小且 `S-` 最大，所以最优。

## 9. AHP

### 9.1 AHP 晋升问题的步骤

**题目：**  
某单位要在 A1、A2、A3 三名职员中选择晋升者。准则包括工作年限、教育程度、工作能力、道德品质。说明用 AHP 解决该问题的完整步骤，并解释一致性检验的作用。

**答案解析：**

1. 建立层次结构：

   ```text
   目标层：选择晋升者
   准则层：工作年限、教育程度、工作能力、道德品质
   方案层：A1、A2、A3
   ```

2. 对准则做成对比较，形成正互反矩阵 `A=(a_ij)`，其中 `a_ij` 表示准则 `i` 相对准则 `j` 的重要性。
3. 求最大特征根对应的特征向量，并归一化为准则权重。
4. 对每个准则下的方案再做成对比较，得到方案相对该准则的权重。
5. 计算综合权重：

   ```text
   方案综合权重 = 方案层权重矩阵 * 准则权重向量
   ```

6. 做一致性检验：

   ```text
   CI = (lambda_max-n)/(n-1)
   CR = CI/RI
   ```

7. 通常 `CR<0.1` 认为判断矩阵一致性可接受。
8. 一致性检验的作用是防止主观比较自相矛盾。例如 A 比 B 重要、B 比 C 重要，却又认为 C 远比 A 重要，就可能导致一致性差。

### 9.2 三准则成对比较矩阵求权重

**题目：**  
三个准则 C1、C2、C3 的成对比较矩阵为：

```text
A = [ 1    2    4
      1/2  1    2
      1/4  1/2  1 ]
```

求准则权重，并判断是否完全一致。

**答案解析：**

1. 观察矩阵可知：

   ```text
   C1:C2 = 2:1
   C2:C3 = 2:1
   C1:C3 = 4:1
   ```

2. 这三组关系完全匹配，因此权重比例为：

   ```text
   C1:C2:C3 = 4:2:1
   ```

3. 归一化：

   ```text
   w = (4/7, 2/7, 1/7)
     = (0.5714, 0.2857, 0.1429)
   ```

4. 因为 `a_ij=w_i/w_j` 对所有元素都成立，所以矩阵完全一致。
5. 完全一致时：

   ```text
   lambda_max = n = 3
   CI = 0
   CR = 0
   ```

6. 因此一致性检验通过。

## 10. 概率模型：二项分布、贝叶斯、全概率

### 10.1 二项分布与超额售票

**题目：**  
飞机有 20 个座位，航空公司卖出 22 张票。每名购票旅客不登机概率为 `0.1`，且相互独立。求没有旅客被拒载的概率。

**答案解析：**

1. 设 `r` 为不登机人数。因为卖出 22 张票，每人不登机概率 0.1，所以：

   ```text
   r ~ Bin(22, 0.1)
   ```

2. 超卖了 `q=2` 张票。没有旅客被拒载等价于至少 2 人不登机，即：

   ```text
   P(r>=2)
   ```

3. 用补事件计算：

   ```text
   P(r>=2)=1-P(r=0)-P(r=1)
   ```

4. 代入二项分布：

   ```text
   P(r=0)=0.9^22≈0.0985
   P(r=1)=C(22,1)*0.1*0.9^21≈0.2407
   ```

5. 所以：

   ```text
   P(r>=2)=1-0.0985-0.2407=0.6608
   ```

6. 没有旅客被拒载的概率约为 `66.08%`。

### 10.2 全概率与贝叶斯诊断

**题目：**  
某病患病率为 `2%`。检测灵敏度为 `P(+|D)=0.95`，误报率为 `P(+|not D)=0.08`。若某人检测为阳性，求其真正患病的概率。

**答案解析：**

1. 设 `D` 表示患病，`+` 表示检测阳性。
2. 已知：

   ```text
   P(D)=0.02
   P(not D)=0.98
   P(+|D)=0.95
   P(+|not D)=0.08
   ```

3. 先用全概率公式求阳性概率：

   ```text
   P(+) = P(D)P(+|D)+P(not D)P(+|not D)
        = 0.02*0.95 + 0.98*0.08
        = 0.019 + 0.0784
        = 0.0974
   ```

4. 用贝叶斯公式：

   ```text
   P(D|+) = P(D)P(+|D)/P(+)
          = 0.019/0.0974
          ≈ 0.1951
   ```

5. 真正患病概率约为 `19.51%`。
6. 易错点：检测阳性后不能直接说患病概率是 95%。95% 是“患病时检测阳性”的条件概率，不是“阳性时患病”的后验概率。

## 11. 线性拟合：最小二乘与参数估计

### 11.1 热敏电阻线性拟合

**题目：**  
温度 `t` 与电阻 `R` 的实验数据如下：

| t/摄氏度 | 20.5 | 32.7 | 51.0 | 73.0 | 95.7 |
|---:|---:|---:|---:|---:|---:|
| R/欧 | 765 | 826 | 873 | 942 | 1032 |

用 `R=at+b` 做最小二乘拟合，并预测 `t=60` 摄氏度时的电阻。

**答案解析：**

1. 最小二乘目标是：

   ```text
   min sum_i (R_i-(a t_i+b))^2
   ```

2. 根据已有复习材料计算，拟合参数为：

   ```text
   a≈3.3987
   b≈702.0968
   ```

3. 拟合直线为：

   ```text
   R≈3.3987t+702.0968
   ```

4. 代入 `t=60`：

   ```text
   R(60)≈3.3987*60+702.0968≈906.0
   ```

5. 因为 `60` 在实验温度范围内，是插值预测，可信度比外推更高。
6. 这组数据的 `R^2≈0.993`，说明线性拟合效果较好。

### 11.2 手算一元线性回归参数

**题目：**  
给定 3 个观测点：

```text
(1,2), (2,3), (3,5)
```

用最小二乘拟合 `y=ax+b`，求 `a,b`，并预测 `x=4` 时的 `y`。

**答案解析：**

1. 先计算统计量：

   ```text
   n=3
   sum x=6
   sum y=10
   sum x^2=14
   sum xy=23
   ```

2. 斜率公式：

   ```text
   a = [n sum xy - (sum x)(sum y)] / [n sum x^2 - (sum x)^2]
   ```

3. 代入：

   ```text
   a = (3*23-6*10)/(3*14-6^2)
     = 9/6
     = 1.5
   ```

4. 截距：

   ```text
   b = (sum y - a sum x)/n
     = (10-1.5*6)/3
     = 1/3
   ```

5. 拟合直线为：

   ```text
   y=1.5x+1/3
   ```

6. 预测 `x=4`：

   ```text
   y=1.5*4+1/3=6.333...
   ```

7. 答案为 `y≈6.33`。

## 12. PCA 降维

### 12.1 根据特征值选择主成分

**题目：**  
某数据标准化后得到 3 个变量的相关矩阵，其特征值为：

```text
lambda1=2.20, lambda2=0.60, lambda3=0.20
```

若希望累计贡献率至少达到 85%，应保留几个主成分？说明理由。

**答案解析：**

1. 标准化后 3 个变量的相关矩阵特征值总和为变量数：

   ```text
   sum lambda = 2.20+0.60+0.20=3.00
   ```

2. 第一主成分贡献率：

   ```text
   2.20/3.00=73.33%
   ```

3. 前两个主成分累计贡献率：

   ```text
   (2.20+0.60)/3.00=93.33%
   ```

4. 只取 1 个主成分不足 85%，取 2 个主成分达到 93.33%。
5. 因此应保留 `2` 个主成分。
6. 解释：PCA 不是简单删变量，而是把原变量旋转成互不相关的新方向，并优先保留方差最大的方向。

### 12.2 二维相关矩阵的主成分方向

**题目：**  
两个标准化变量的相关矩阵为：

```text
R = [1   0.8
     0.8 1  ]
```

求两个特征值，并说明第一主成分的大致含义。

**答案解析：**

1. 特征方程：

   ```text
   det(R-lambda I)=0
   ```

2. 对矩阵：

   ```text
   |1-lambda   0.8     |
   |0.8        1-lambda|
   ```

3. 行列式为：

   ```text
   (1-lambda)^2-0.64=0
   ```

4. 得：

   ```text
   1-lambda = ±0.8
   lambda1=1.8, lambda2=0.2
   ```

5. 第一主成分贡献率：

   ```text
   1.8/(1.8+0.2)=90%
   ```

6. 对 `lambda1=1.8`，特征向量方向约为 `(1,1)`，归一化后为：

   ```text
   (1/sqrt(2), 1/sqrt(2))
   ```

7. 因此第一主成分大致表示两个变量的“共同水平”。由于两个变量高度正相关，一个综合指标就能保留约 90% 信息。

## 13. 博弈论

### 13.1 囚徒困境的纯策略纳什均衡

**题目：**  
甲乙两人被分别审讯。若二人都不坦白，各判 2 年；若二人都坦白，各判 5 年；若一人坦白另一人不坦白，坦白者 0 年，不坦白者 10 年。把刑期越少看作收益越高，求纯策略纳什均衡，并说明它是否帕累托最优。

**答案解析：**

1. 对甲来说：

   - 若乙坦白，甲坦白判 5 年，不坦白判 10 年，甲应坦白。
   - 若乙不坦白，甲坦白判 0 年，不坦白判 2 年，甲仍应坦白。

2. 所以坦白是甲的占优策略。
3. 对乙同理，坦白也是乙的占优策略。
4. 因此纯策略纳什均衡为：

   ```text
   (坦白, 坦白)
   ```

5. 该结果下二人各判 5 年。
6. 但若二人都不坦白，则各判 2 年，对二人都更好。
7. 因此 `(坦白,坦白)` 是纳什均衡，但不是帕累托最优。这说明个体理性不一定导致整体最优。

### 13.2 点球博弈的混合策略均衡

**题目：**  
点球时，罚球队员可射左或射右，守门员可扑左或扑右。罚球队员的进球概率矩阵为：

|  | 守门员扑左 | 守门员扑右 |
|---|---:|---:|
| 罚左 | 0.4 | 0.8 |
| 罚右 | 0.9 | 0.5 |

设罚球队员以概率 `p` 罚左，守门员以概率 `q` 扑左。求混合策略均衡。

**答案解析：**

1. 罚球队员要让守门员在扑左和扑右之间无差异。
2. 若守门员扑左，罚球队员期望进球率为：

   ```text
   0.4p + 0.9(1-p) = 0.9 - 0.5p
   ```

3. 若守门员扑右，罚球队员期望进球率为：

   ```text
   0.8p + 0.5(1-p) = 0.5 + 0.3p
   ```

4. 令二者相等：

   ```text
   0.9 - 0.5p = 0.5 + 0.3p
   p = 0.5
   ```

5. 守门员要让罚球队员在罚左和罚右之间无差异。
6. 若罚左，进球率为：

   ```text
   0.4q + 0.8(1-q) = 0.8 - 0.4q
   ```

7. 若罚右，进球率为：

   ```text
   0.9q + 0.5(1-q) = 0.5 + 0.4q
   ```

8. 令二者相等：

   ```text
   0.8 - 0.4q = 0.5 + 0.4q
   q = 0.375
   ```

9. 混合策略均衡为：

   ```text
   罚球队员：50% 罚左，50% 罚右
   守门员：37.5% 扑左，62.5% 扑右
   ```

10. 均衡进球率为：

    ```text
    0.8 - 0.4*0.375 = 0.65
    ```

11. 这类题的核心不是“随机各一半”，而是让对方无法通过改变策略提高收益。

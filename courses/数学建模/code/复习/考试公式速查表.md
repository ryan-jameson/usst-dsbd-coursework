# 考试公式速查表

> 用途：考场看到题目时快速想起“该用哪个公式”。不是普通总结。

## 1. 建模/优化通用

- 建模流程：现实问题 -> 假设 -> 变量/参数 -> 模型 -> 求解 -> 检验/解释。
- 优化三要素：决策变量 `x`；目标函数 `f(x)`；约束 `g_i(x)<=0, h_j(x)=0`。
- 数学规划一般式：`max/min f(x)`, `s.t. g_i(x)<=0, h_j(x)=0, a_i<=x_i<=b_i`。
- 多目标转单目标：`F(x)=w1 f1(x)+...+wq fq(x)`。
- 边界约束改写：`a_i<=x_i<=b_i` -> `x_i-b_i<=0, a_i-x_i<=0`。

## 2. 初等模型/估计

- 匀加速：`v=at`, `s=1/2 at^2`。
- 减速带：`t=cv+d`, `a=1/c`；总间距约 `s=vmax^2/(2a1)+vmax^2/(2|a2|)`。
- 课件数值：`vmax=40 km/h=11.1 m/s`, `c1=0.4536`, `c2=-0.6084`, `s≈66.5m`。
- 连续编号抽样估计：样本数 `n`，最大编号 `m`，常用估计 `N≈(n+1)m/n-1`。

## 3. 线性规划/0-1规划

- LP 标准：`max z=c^T x`, `s.t. Ax<=b, x>=0`。
- 奶制品模型：`max z=72x1+64x2`；`x1+x2<=50`；`12x1+8x2<=480`；`3x1<=100`；`x>=0`。
- 奶制品最优：`x1=20, x2=30, z=3360`。
- 影子价格：`shadow_i=Δz*/Δb_i`；课件：牛奶 `48`，时间 `2`，A1能力 `0`。
- 敏感性：最优基/最优解不变时，`c` 或 `b` 的允许变化范围。
- 0-1变量：`x_i in {0,1}`。
- 逻辑：`x=>y` 写 `x<=y`；`x=>not y` 写 `x+y<=1`。
- 至多一：`x+y<=1`；至少一：`x+y>=1`；恰一：`x+y=1`。
- 指派：每任务一人 `sum_i x_ij=1`；每人至多一任务 `sum_j x_ij<=1`。
- 类别最低要求：`sum_{i in C} x_i >= k`。
- 可分离规划折线：若 `b_k<=x<=b_{k+1}`，`x=z_k b_k+z_{k+1}b_{k+1}`，`z_k+z_{k+1}=1`，`c(x)=z_k c(b_k)+z_{k+1}c(b_{k+1})`。

## 4. 生产周期/库存

- 库存量：`q(t)=Q-rt`，周期末 `q(T)=0`，所以 `Q=rT`。
- 周期平均库存：`Q/2`；周期库存面积：`QT/2`。
- 平均日费用：`C(T)=c1/T + c2*r*T/2`。
- 最优周期：`T*=sqrt(2c1/(c2*r))`；最优批量：`Q*=rT*`。
- 敏感度：`S(T,c1)=1/2`, `S(T,c2)=-1/2`, `S(T,r)=-1/2`。

## 5. 森林救火

- 目标：`min C(x)=f1(x)+f2(x)`。
- 常用表达：`C(x)=c1 B(t2)+c2 x(t2-t1)+c3 x`。
- 火势：救火前 `dB/dt` 随 `t` 增；救火后火势速度系数约 `β-λx`。
- 临界人数：`β/λ` 是阻止火势继续扩大的最低队员数。

## 6. Logistic/传染病/信息传播

- Logistic 增长：`dx/dt=r x(1-x/N)`。
- 捕捞：`h(x)=Ex`，有捕捞时 `dx/dt=r x(1-x/N)-Ex`。
- 最大持续产量：平衡鱼量 `x*=N/2`，产量最大约 `h_max=rN/4`。
- 收入/成本：`T=p h(x)=pEx`，`S=cE`，利润 `R(E)=T-S`。
- SI：`s+i=1`，`di/dt=λ s i=λ i(1-i)`；`i=1/2` 时增长最快。
- SIS：`di/dt=λsi-μi`；若 `λ>μ`，`i(∞)=1-μ/λ`；若 `λ<μ`，`i->0`。
- SIR：`ds/dt=-λsi`, `di/dt=λsi-μi`, `dr/dt=μi`。
- 基本感染数：`σ=λ/μ=λ*(1/μ)`；`σs>1` 患者增，`σs<1` 患者减。
- 信息传播差分：`p_{k+1}-p_k=c p_k(N-p_k)`。
- 传播参数：`c=Δp_k/[p_k(N-p_k)]`。

## 7. 状态决策/遗传转移

- 状态转移：`s_{i+1}=T(s_i,d_i)`；商人过河可写 `s_{i+1}=s_i+(-1)^i d_i`。
- 商人状态：`s=(x,y)`；`x` 商人，`y` 随从。
- 容许状态：`S={(3,y),(0,y), y=0..3} U {(1,1),(2,2)}`。
- 船决策：`d=(u,v)`，`1<=u+v<=2`。
- 概率转移矩阵：`P=(p_ij)`，`p_ij=P(下一状态 j | 当前状态 i)`。
- 遗传：`D=dd`, `H=dr`, `R=rr`。
- 与 H 繁殖：`D-H -> (D,H,R)=(1/2,1/2,0)`；`H-H=(1/4,1/2,1/4)`；`R-H=(0,1/2,1/2)`。
- 条件概率例：`P(D|DH)=P(d|D)P(d|H)=1*1/2=1/2`；`P(R|HH)=1/2*1/2=1/4`。

## 8. 席位分配/投票

- Hamilton：`q_i=N p_i/P`；先给 `floor(q_i)`；余席按 `r_i=q_i-floor(q_i)` 从大到小给。
- 公平思想：每席代表人数 `p_i/n_i` 越接近越公平。
- EP 相等比例法：优先值 `Q_i=p_i/sqrt(n_i(n_i+1))`；下一席给 `Q_i` 最大者。
- Borda 计数：`m` 个候选，第一名 `m` 分，第二名 `m-1` 分，最后 `1` 分；总分最高胜。

## 9. 多属性决策

- 决策矩阵：`D=(d_ij)`，行=方案，列=属性。
- 费用型转效益型：可用 `d'_ij=1/d_ij`。
- 最大化标准化：`r_ij=d_ij/max_i d_ij`。
- 归一化：`r_ij=d_ij/sum_i d_ij`。
- 模一化：`r_ij=d_ij/sqrt(sum_i d_ij^2)`。
- 信息量：`I(x_i)=-log p(x_i)`。
- 熵权：`E_j=-k sum_i r_ij ln r_ij`, `k=1/ln m`。
- 区分度：`F_j=1-E_j`；权重：`w_j=F_j/sum_j F_j`。
- SAW：`v_i=sum_j w_j r_ij`。
- WP：`v_i=prod_j d_ij^{w_j}`；费用型属性权重取负。
- TOPSIS：`v_ij=w_j r_ij`。
- TOPSIS 距离：`S_i^+=sqrt(sum_j(v_ij-v_j^+)^2)`, `S_i^-=sqrt(sum_j(v_ij-v_j^-)^2)`。
- TOPSIS 接近度：`C_i=S_i^-/(S_i^+ + S_i^-)`，越大越优。

## 10. AHP 层次分析

- 成对比较矩阵：`A=(a_ij)`，`a_ij=w_i/w_j`，`a_ji=1/a_ij`，`a_ii=1`。
- 权重：求最大特征根对应特征向量，`Aw=λ_max w`，再归一化。
- 一致性指标：`CI=(λ_max-n)/(n-1)`。
- 一致性检验：`CR=CI/RI<0.1` 通过。

## 11. 二项分布/超额售票

- 不登机人数：`r ~ Bin(n+q,p)`。
- 概率：`f(r)=C(n+q,r) p^r (1-p)^(n+q-r)`。
- 收益函数：
  - 若 `r<=q`：`S(r,q)=s1*n - s2*(q-r)`。
  - 若 `r>q`：`S(r,q)=s1*(n+q-r)`。
- 期望收益：`E(q)=sum_{r=0}^{n+q} S(r,q)f(r)`。
- 最优 q 判据：`P(r<=q)=sum_{r=0}^q C(n+q,r)p^r(1-p)^(n+q-r) >= s1/(s1+s2)=1/(1+s)`，`s=s2/s1`。
- 声誉约束：无法登机人数超过 `j` 的概率 `P_j(q)=P(q-r>j)=sum_{r=0}^{q-j-1} f(r)<=α`。

## 12. 概率/贝叶斯

- 加法公式：`P(A∪B)=P(A)+P(B)-P(A∩B)`；互斥时 `P(A∩B)=0`。
- 乘法公式：`P(A∩B)=P(A)P(B|A)=P(B)P(A|B)`。
- 独立：`P(B|A)=P(B)`，所以 `P(A∩B)=P(A)P(B)`。
- 全概率：`P(B)=sum_i P(A_i)P(B|A_i)`。
- 贝叶斯：`P(A_i|B)=P(A_i)P(B|A_i)/sum_k P(A_k)P(B|A_k)`。
- 朴素贝叶斯：`P(X|C_i)=prod_j P(x_j|C_i)`。
- 分类打分：`score(i)=P(C_i)prod_j P(x_j|C_i)`，分数最大者为类别。
- 二值特征拉普拉斯修正：`P(x=是|C)=(该类中x=是次数+1)/(该类样本数+2)`。
- 评论例：`score(pos)=0.1389`, `score(neg)=0.0023`，判为好评。
- Warner 模型：`P(C)=pP(A)+(1-p)(1-P(A))`。
- Warner 解作弊率：`p=[P(C)+P(A)-1]/[2P(A)-1]`。
- Simmons 模型：`P(C)=pP(A)+p0(1-P(A))`。
- Simmons 解作弊率：`p=[P(C)-p0(1-P(A))]/P(A)`。

## 13. 统计/回归/检验

- 一元线性回归：`y=b0+b1x+ε`，常设 `ε~N(0,σ^2)`。
- 多元线性回归：`y=b0+b1x1+...+bkxk+ε`。
- 交互项：`y=b0+b1x1+b2x2+b3x1x2+ε`。
- 决定系数：`R^2=1-SSR/SST=1-sum_i(y_i-yhat_i)^2/sum_i(y_i-ybar)^2`。
- 相关系数：`r_XY=Cov(X,Y)/sqrt(Var(X)Var(Y))`。
- 假设检验：设 `H0/H1`，显著性水平 `α`；统计量落入拒绝域 `W` 或 `p<α` -> 拒绝 `H0`。
- 自相关判断：残差 `e_t` 与 `e_{t-1}` 同号多 -> 正自相关；异号多 -> 负自相关。
- 一阶自回归例：`y_t` 可由 `y_{t-1}, x_t, x_{t-1}` 等解释。

## 14. PCA/降维

- 标准化：每个变量均值 `0`，方差 `1`。
- 相关矩阵：`R_ij=Cov(X_i,X_j)/(σ_i σ_j)`。
- 特征方程：`det(R-λI)=0`。
- 特征向量：`(R-λ_i I)v_i=0`。
- 累计贡献率：`sum_{i=1}^k λ_i / sum_i λ_i`，超过阈值就取前 `k` 个主成分。

## 15. 博弈

- 博弈四要素：参与人 `N`，策略集 `A_i`，收益 `u_i`，均衡。
- 零和博弈：`u_2(a1,a2)=-u_1(a1,a2)`。
- 纯策略 Nash 均衡：对任意单方偏离，`u_i(a_i*,a_-i*) >= u_i(a_i,a_-i*)`。
- 点球收益矩阵：罚球队员 `u1(i,j)=m_ij`，守门员 `u2(i,j)=-m_ij` 或 `1-m_ij`。
- 报价博弈成交：若 `p_b>=p_s`，成交价 `p=(p_b+p_s)/2`。
- 成交收益：卖方 `U_s=p-v_s`，买方 `U_b=v_b-p`；不成交收益 `0`。
- 贝叶斯纳什均衡：在不知道对方类型时，单方改变策略不能提高期望效用。

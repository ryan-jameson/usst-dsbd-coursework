## 正面：期中内容 - 最优化问题

### 1. 数学建模与优化
- 数学模型：现实对象 + 特定目的 + 简化假设 + 数学工具得到的数学结构。
- 数学建模：实际问题 -> 数学问题 -> 求解 -> 解释/检验 -> 回到实际。
- 建模五步：目标分析 -> 合理假设 -> 建> 求参数/解 -> 模拟/检验。
- 最优化：在所有可行方案中选使目标最优的方案；先是理念，再是方法。
- 三要素：决策变量 x；目标函数 f(x)；约束 g_i(x)<=0, h_j(x)=0。
- 数学规划一般式：max/min f(x), s.t. g_i(x)<=0, h_j(x)=0, a_k<=x_k<=b_k, x in R^n。
- 可行域 D：满足全部约束的点集；起作用约束：最优点处等号成立的约束。
- 目标函数：显式公式/拟合曲线；隐式仿真/程序输出；多目标常用加权和转单目标。

### 2. 初等模型
- 初等模型：机理简单，用静态、线性、确定性、初等数学；能简单就不要复杂。
- 减速带：v=at, s=1/2 at^2；加速+减速距离相加；vmax=40km/h=11.1m/s。
- 减速带结论：测试拟合 t=cv+d，a=1/c；c1=0.4536,c2=-0.6084，间距约 66.5m/67m。
- 坦克/出租车估计：编号连续+均匀抽样；用最大编号/样本间距估总量；若从1编号，N≈(n+1)m/n - 1。

### 3. 线性规划 LP
- LP 标准形：max z=c^T x, s.t. Ax<=b, x>=0；几何：可行域凸多边形，最优解在顶点。
- LP 四假设：比例性(贡献与变量成比例)；可加性(各变量贡献相加)；连续性(x可取实数)；确定性(参数确定)。
- LP 建模步骤：定变量 -> 写目标 -> 写资源/能力/非负约束 -> 求解 -> 看松弛/影子价/敏感性 -> 解释。
- 奶制品变量：x1=用于 A1 的牛奶桶数，x2=用于 A2 的牛奶桶数。
- 奶制品模型：max z=72x1+64x2；x1+x2<=50；12x1+8x2<=480；3x1<=100；x1,x2>=0。
- 奶制品最优解：B(20,30)，z=3360；即 20 桶做 A1，30 桶做 A2。
- 松弛：牛奶0、时间0、A1加工能力40；紧约束=原料、时间。
- 影子价格：资源增加 1 单位带来的最优目标增量；牛奶48、时间2、A1能力0。
- 解释题：35元买1桶牛奶？买，因为35<48；最多买10桶。临时工最高2元/h。
- 敏感性：最优基/最优解不变时，系数或 RHS 允许变化范围。
- 奶制品敏感性：x1利润系数范围(64,96)，x2范围(48,72)；A1利润30元/kg -> 系数90，不改计划。

### 4. 规划模型区别
- 非线性规划 NLP：目标或约束有非线性。
- 二次规划 QP：目标为二次函数，常见边际收益递减；约束常线性。
- 可分离规划：目标/成本可分段线性，用折线/辅助变量转 LP。
- 整数规划 IP：部分/全部变量必须为整数。
- 0-1规划：x_i in {0,1}，表示选/不选、是/否；常见：指派、选址、背包、项目选择。

### 5. 0-1 逻辑约束
- 甲=>乙：x1<=x2。甲=>不乙：x1+x2<=1。
- 至多选一：x1+x2<=1；至少选一：x1+x2>=1；恰选一：x1+x2=1。
- 若 x3=1 则 x1=x2=1：x3<=x1, x3<=x2。
- 指派：每任务恰1人 sum_i x_ij=1；每人最多1项 sum_j x_ij<=1。
- 类别最低要求：sum_{i in 类别} x_i >= 要求数。
- 多目标处理：先主后次(先项目数最少，再KPI最大)；或加权成复合目标。

## 背面：期末内容 - 决策问题

### 1. 状态决策与商人过河
- 状态 s：系统某时刻取值；决策 d：可选择动作；转移：s_{t+1}=T(s_t,d_t)。
- 离散系统：有限状态集合 S；容许决策 D(s)；起点 s0；终点/目标；约束每步合法。
- 商人过河状态：s=(x,y)，x=此岸商人数，y=此岸随从数。
- 全状态 E={(x,y)|x,y=0,1,2,3}；容许状态 S={(3,y),(0,y), y=0..3} U {(1,1),(2,2)}。
- 决策 d=(u,v)：船上 u 商人、v 随从；1<=u+v<=2；去程减 d，返程加 d。
- 目标：从 s0=(3,3) 经有限次合法转移到 sn=(0,0)，中间状态均在 S。
- 一组解： (3,3)-(0,2)->(3,1)+(0,1)->(3,2)-(0,2)->(3,0)+(0,1)->(3,1)-(2,0)->(1,1)+(1,1)->(2,2)-(2,0)->(0,2)+(0,1)->(0,3)-(0,2)->(0,1)+(0,1)->(0,2)-(0,2)->(0,0)。

### 2. 概率决策与遗传转移
- 概率转移矩阵 P=(p_ij)：p_ij=在当前状态 i 下转到状态 j 的概率；分布向量按约定乘 P 更新。
- 遗传状态：D=dd 优种，H=dr 混种，R=rr 劣种；后代各取父母一个基因。
- 与 H 交配转移(D,H,R)：D-H=(1/2,1/2,0)；H-H=(1/4,1/2,1/4)；R-H=(0,1/2,1/2)。
- 六种父母组合：DD, RR, DH, DR, HH, HR；核心是由父母类型决定后代 D/H/R 概率。
- 例：P(D|DH)=P(d|D)P(d|H)=1*1/2=1/2；P(R|HH)=1/2*1/2=1/4。

### 3. 席位分配
- Hamilton：q_i=N p_i/P；先给 floor(q_i)；剩余席位按小数 r_i=q_i-floor(q_i) 从大到小给。
- Hamilton 不公平：N 增加可能使某方 n_i 减少；人口增长更快也可能反而少席。
- 公平度思想：理想为 p_i/n_i 相等；比较“每席代表人数”的相对不公平度。
- EP 相等比例法：逐席分配；优先值 Q_i=p_i/sqrt(n_i(n_i+1))；下一席给 Q 最大方。
- 例：19席起点(甲10,乙6,丙3)，第20席给甲 -> (11,6,3)，第21席给丙 -> (11,6,4)。

### 4. 投票方法
- 一次投票：每个选民给候选人完整排序；选举方法决定如何由排序得到获胜者。
- 简单多数法：第一名票最多者胜；例 B 胜；缺点：只看第一名。
- 单轮决胜法：第一名票前两名进入决胜，再简单多数；例 C 胜。
- 系列决胜法：每轮淘汰第一名票最少者，剩两人决胜；例 C 胜。
- Coombs 法：每轮淘汰倒数第一票最多者；例 D 胜。
- Borda 计数法：m个候选，第一名m分、最后1分，总分最高胜；例 D 胜。
- 关键结论：同一组选民偏好，不同统计规则会得不同获胜者；差异来自使用排序信息的多少和淘汰方向。

### 5. 多属性决策
- 四要素：目标；备选方案 A_i；属性 X_j；权重 w_j；综合方法。
- 决策矩阵 D=(d_ij)：行=方案，列=属性；d_ij=方案 i 在属性 j 的取值。
- 属性类型：效益型越大越好；费用型越小越好，先转效益型，如 d'_ij=1/d_ij。
- 标准化：最大化 r_ij=d_ij/max_i d_ij；归一化 r_ij=d_ij/sum_i d_ij；模一化 r_ij=d_ij/sqrt(sum_i d_ij^2)。
- 熵权法：E_j=-k sum_i r_ij ln r_ij, k=1/ln m；F_j=1-E_j；w_j=F_j/sum_j F_j。
- 熵含义：某属性分布越平均，E越大、区分度F越小、权重越小。
- 汽车例熵权：w=(0.5330,0.3293,0.1377)^T，价格差异最大所以权重最大。
- SAW：v_i=sum_j w_j r_ij；前提=属性独立且可互补；简单直观。
- WP：v_i=prod_j d_ij^{w_j}；费用型权重取负；强调均衡，有“一票否决”效果。
- TOPSIS：v_ij=w_j r_ij；取正理想 v+、负理想 v-；S_i+=sqrt(sum(v_ij-v_j+)^2)，S_i-=sqrt(sum(v_ij-v_j-)^2)；C_i=S_i-/(S_i++S_i-)，C越大越优。
- 多属性一般步骤：定目标/方案/属性 -> 得 D 和 w -> 统一属性方向并标准化 -> SAW/WP/TOPSIS 排序。
- 汽车例结论：SAW、WP、TOPSIS 均偏向 A3>A2>A1；TOPSIS差别更大。

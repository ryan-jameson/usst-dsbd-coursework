# WebScraper.io 商品数据采集 GUI 实验

本项目用于“大数据采集技术”课程实验：通过本地 GUI 程序采集 WebScraper.io 官方测试电商站点的商品数据，并展示表格结果与统计分析。

## 运行方式

在当前目录打开终端，执行：

```powershell
python scraper_gui.py
```

程序仅使用 Python 标准库，不需要额外安装第三方依赖。

如果要复制到其他电脑运行，可参考 `发布运行说明.md`。有 Python 的电脑可直接双击 `run.bat`；没有 Python 的 Windows 电脑建议先用 `build_exe.bat` 打包为 exe。

## 功能

- 选择采集分类：Laptops、Tablets、Touch phones 或全部分类
- 设置最大采集页面数和请求间隔
- 对已采集商品数据进行关键词搜索
- 可按全部字段、商品名、分类、描述、价格、评论数筛选
- 选中搜索结果后可双击或点击“打开网页”跳转到商品详情页
- 展示商品分类、名称、价格、描述、评论数、详情页链接
- 自动统计商品数量、平均价格、价格范围、评论总数、评论最多商品
- 按分类展示商品数量柱状图
- 导出当前表格中的 CSV 文件，便于后续用 Excel 或 Python 分析

## 默认采集网站

```text
https://webscraper.io/test-sites/e-commerce/static
```

这是 WebScraper.io 官方提供的测试站点，适合作为爬虫实验目标。

## 实验报告可写内容

1. 实验目的：掌握网页结构分析、数据采集、数据清洗、统计展示和 CSV 导出。
2. 实验对象：WebScraper.io 官方电商测试站。
3. 数据字段：分类、商品名、价格、描述、评论数、详情页链接、图片链接。
4. 实现方法：使用 Tkinter 构建 GUI，使用 urllib 请求页面，使用 HTMLParser 解析商品卡片。
5. 检索跳转：对采集结果进行关键词检索，选择目标商品后调用浏览器打开详情页。
6. 分析结果：统计商品总数、平均价格、最高价、最低价、评论总数和各分类商品数量。
7. 注意事项：设置请求间隔，使用公开测试站，避免对真实网站造成压力。

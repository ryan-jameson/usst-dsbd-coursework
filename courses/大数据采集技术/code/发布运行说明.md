# 程序发布与跨电脑运行说明

本程序只使用 Python 标准库，不需要安装 requests、bs4、pandas 等第三方库。

## 方案一：目标电脑已安装 Python

把整个文件夹复制到目标电脑，然后双击：

```text
run.bat
```

或者在终端中执行：

```powershell
python scraper_gui.py
```

适合老师电脑或实验室电脑已经安装 Python 的情况。

## 方案二：目标电脑没有 Python

在你自己的电脑上先打包成 exe：

```text
双击 build_exe.bat
```

打包完成后，生成的文件在：

```text
dist\WebScraperGUI.exe
```

把这个 exe 复制到其他 Windows 电脑上即可运行。

## 注意事项

- 第一次执行 `build_exe.bat` 需要联网安装 PyInstaller。
- 目标电脑运行程序时需要能访问 `https://webscraper.io/`，否则无法爬取在线数据。
- 如果 Windows 安全提示拦截 exe，选择“更多信息”后继续运行即可。
- exe 是按当前系统打包的：Windows 上打包出来的是 Windows exe；如果要给 macOS 或 Linux 使用，需要在对应系统上重新打包。

**[答案 1-L02] 相关与因果**

> 原题：结合一个实际案例说明为什么大数据强调“相关而非因果”，以及这一思维可能带来的风险和改进措施。

- **评分点1：**含义：大数据分析常先利用相关性快速发现模式，不等于否认因果研究。
- **评分点2：**案例：雨伞销量与交通拥堵可能同时上升，它们相关，但共同原因可能是降雨，不能说买雨伞导致拥堵。
- **评分点3：**风险：把相关误当因果会形成错误决策、歧视性规则或资源误配。
- **评分点4：**改进：结合业务机理、对照实验、时间顺序、混杂因素分析和专家判断验证因果。

# 五章开卷复习材料设计

## 目标
生成两份互补的打印材料：一份帮助在实体教材中快速定位，一份替代打印全部课程 PPT。

## 输出一：教材重点.pdf
- 封面说明两种页码的含义。
- 总目录按第 1、2、3、5、6 章排列。
- 每章先给速查表：重点、检索关键词、教材目录位置、教材印刷页码、教材 PDF 页码、对应 PPT 页码。
- 速查表后收录教材关键原页或关键区域截图；截图保留足够上下文，不只截孤立句子。
- 章节分隔、页眉和页脚统一，便于纸质装订。

## 输出二：补充复习内容.pdf
- 以 PPT 为唯一整理来源，按知识逻辑重排而非逐页照抄。
- 删除课程介绍、学习目标重复页、装饰页、完全重复内容、低信息密度过渡页。
- 保留定义、特点、分类、体系结构、工作流程、优缺点、比较、公式、典型工具和关键操作。
- 每章提供“本章结构”“核心知识点”“易混点/比较”“速查关键词”。
- 对重复出现在多页的同一知识点合并为一处，并保留来源 PPT 页码范围。

## 边界
- 不覆盖或修改任何输入 PDF。
- 不把教材外常识伪装成课程内容。
- OCR 不确定内容需回看原页确认；无法确认时不写入成品。

## 验收标准
- 两份目标 PDF 均存在且可打开。
- 目录、页码、章节顺序和五章覆盖完整。
- 中文文本可检索；教材截图清晰可读。
- 渲染页不存在文字裁切、重叠、黑块和缺字。

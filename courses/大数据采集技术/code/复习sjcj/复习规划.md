# 两天复习规划

> 默认每天约8-8.5小时有效复习；目标是核心概念能复述、流程比较能默写、公式能选用、资料能在60秒内定位。

## 总原则

- 每个知识块执行：20分钟理解 -> 5分钟合书回忆 -> 10分钟查漏并标页码。
- 只抄结构、比较、公式和错因；不大段誊写教材或讲义。
- 红色=不会，黄色=不稳定，绿色=能独立讲/做；每天结束只修红黄项。
- 22:00停止学习，保证睡眠，不以熬夜换低质量阅读。

## 60秒检索题

1. HDFS读数据时，NameNode和DataNode分别负责什么？
2. HBase与关系数据库在索引、存储和扩展上有什么区别？
3. Flume的Source、Channel、Sink各自做什么？
4. Scribe的Buffer Store如何实现故障恢复？
5. robots.txt中User-agent、Disallow、Allow、*、$分别表示什么？
6. 深度优先、广度优先、OPIC和最佳优先如何选择？
7. 非对称二元属性为什么不计共同为0的t？
8. Min-Max、Z-score、小数定标分别在什么条件下使用？
9. 数据质量六个维度是什么？
10. 大数据伦理问题与治理对策如何对应？

## 时间不足时的压缩方案

- 每天只有4-5小时：保留第2章、第5章、第6章；第1/3章只做框架和工具比较。
- 计算只做18道P0题；P1题全部取消。
- 检索训练不能取消，至少完成10个关键词各一次。
- 考前最后一小时只看公式选择表、比较表、错题和页签，不再读新内容。

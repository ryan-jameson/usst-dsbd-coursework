# Task Plan: 两天课程复习规划

## Goal
生成一份可以连续执行两天、与现有教材索引和复习讲义精确对应、带检查点和应急压缩方案的 `复习规划.pdf`。

## Phases
- [x] Phase 1: 明确两天目标、默认时长和材料边界
- [x] Phase 2: 核对复习材料页数、章节页码与第六章练习资源
- [x] Phase 3: 编排两天时间块、重点顺序、主动回忆与查找训练
- [x] Phase 4: 生成 `复习规划.md` 和 `复习规划.pdf`
- [x] Phase 5: 检查目录、页码、时间总量、文字可提取性与渲染质量

## Key Questions
1. 两天内哪些内容必须达到“闭卷能说、开卷能找、计算能做”？
2. 如何在章节学习、主动回忆、计算练习和开卷检索之间分配约 16 小时？
3. 时间不足时应保留哪些 P0 内容、舍弃哪些低收益内容？

## Decisions Made
- 默认每天 09:00-22:00 内安排约 8 小时有效学习，含午休、晚休和短休息。
- 第一天完成第1、2、3章与检索系统；第二天完成第5、6章、计算训练和模拟。
- 第6章公式和计算优先级最高，第2章架构与比较次之。
- 原始教材、PPT、已生成的两份复习 PDF 和练习 PDF 全部保持不变。

## Errors Encountered
- 最终核验首次失败：Markdown字符数阈值误按UTF-8字节数设置，且连字符检查与正文不一致；确认是验证条件错误后修正并完整重跑，结果为 `VERIFY_OK`。

## Status
**Complete** - 规划已生成并通过文本、目录、页数、源文件边界和逐页渲染检查。

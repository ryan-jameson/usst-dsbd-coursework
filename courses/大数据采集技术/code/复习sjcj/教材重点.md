  - 框出“5V+1C”六项：大量、多样、价值、高速、准确性、复杂。
- 一句话记忆：答题顺序：定义 → 不是简单堆积 → 5V+1C。
- 易错提醒：教材把 veracity 写作“准确性”；考试若问英文特征，中文和英文一起写。

### 1-03 数据采集与数据预处理的课程定位（P0 必划）

## 第2章 数据采集基础

### 2-01 传统数据采集链与性能指标（P0 必划）

- 教材定位：教材印刷页10；PDF第23页；2.1.1 数据采集概述
- 教材上怎么划：
  - 完整划出数据采集定义中的链条：传感器 → 调整 → 采样 → 量化 → 编码 → 传输 → 计算机。
  - 划“任务就是采集模拟信号并转换成计算机能识别的数字信号”。
  - 圈出性能指标“精度和速度”；旁注：保证精度前提下提高采样速度。
- 一句话记忆：输入是模拟信号，输出是计算机可识别的数字信号。
- 易错提醒：采样只让时间离散；量化、编码后才得到数字信号。

### 2-02 采样定理（P0 必划/会算）

- 教材定位：教材印刷页15；PDF第28页；2.1.2 采样、量化与编码技术
- 教材上怎么划：
  - 框出采样定理的条件和结论，尤其是“采样频率大于等于最高频率的2倍”。
  - 在公式旁写成便于计算的形式：fs ≥ 2fmax；同时写 Ts ≤ 1/(2fmax)。
  - 划采样周期过小/过大的后果：数据量过大；信息丢失与失真。
- 一句话记忆：若最高频率为4 kHz，最低采样频率为8 kHz。
- 易错提醒：题目问‘最低’时取2倍；实际工程采样常留余量，但教材计算按定理。

### 2-03 量化、编码与A/D转换（P0 必划）

- 教材定位：教材印刷页16—17；PDF第29—30页；2.1.2 采样、量化与编码技术
- 教材上怎么划：
  - 划量化定义：用最接近采样幅值的最小数量单位倍数代替该幅值。
  - 划编码定义：把量化信号的数值用二进制代码表示。
  - 给“完成量化和编码的器件是模/数（A/D）转换器”加双下划线。
- 一句话记忆：采样：时间离散；量化：幅值离散；编码：离散值变二进制码。
- 易错提醒：不要把A/D写成只完成采样；教材明确强调量化和编码。

### 2-04 大数据来源、采集挑战与常用方法（P0 必划）

- 教材定位：教材印刷页21、26；PDF第34、39页；2.2.2—2.2.3
- 教材上怎么划：
  - 在印刷页21框出来源：采集器、企业数据库、社交网络、开放数据、GPS、网络痕迹、传感器。
  - 在印刷页26给五个挑战编号：分布、不稳定、无结构与冗余、错误、结构复杂。
  - 给三种常用方法加星：系统日志、ETL、网络爬虫。
- 一句话记忆：来源回答‘从哪里来’，方法回答‘怎么取’，挑战回答‘为什么难’。
- 易错提醒：结构化/非结构化是数据类型，不是采集方法。

### 2-05 ETL的含义、目标与流程（P0 必划）

- 教材定位：教材印刷页27；PDF第40页；2.2.3 利用ETL工具采集
- 教材上怎么划：
  - 划“ETL即数据抽取、转换、加载的过程”。
  - 划ETL目的：整合分散、零乱、标准不统一的数据。
  - 框图2-9，并在下方概括句标出：异构源 → 临时中间层 → 清洗/转换/集成 → 数据仓库/数据集市。
- 一句话记忆：Extract取出，Transform清洗转换，Load装入目标系统。
- 易错提醒：全量/增量是‘抽取’的两种方式，不是整个ETL的两种方式。

## 第2章 数据采集基础（跨教材第7章）

### 2-06 HDFS：NameNode、DataNode、Block与主从结构（P0 必划）

- 教材定位：教材印刷页139—140；PDF第152—153页；教材7.1.2 HDFS
- 教材上怎么划：
  - 划NameNode职责：命名空间、文件/目录操作、DataNode与文件块映射。
  - 划DataNode职责：数据存储与读取；HDFS内部把文件拆成块存于多个DataNode。
  - 划主从结构，并给“用户数据永远不会经过NameNode”加双下划线。
- 一句话记忆：NameNode管元数据和位置；DataNode管真实数据；Client直接找DataNode传数据。
- 易错提醒：SecondaryNameNode不是NameNode的实时热备，它主要合并FsImage与EditLog。

### 2-07 HDFS读、写与块复制流程（P0 必划）

- 教材定位：教材印刷页141；PDF第154页；教材7.1.2 HDFS
- 教材上怎么划：
  - 读：Client把文件名给NameNode → 得到DataNode位置 → Client直接读DataNode。
  - 写：Client请求NameNode → 得到DataNode信息 → 文件分块 → 顺序写入DataNode。
  - 复制：NameNode发现副本不足/节点失效 → 通知DataNode相互复制。
- 一句话记忆：控制信息经过NameNode，真实数据在Client与DataNode之间传输。
- 易错提醒：不要写成NameNode保存文件内容或转发文件数据。

### 2-08 HDFS可靠性：副本、心跳、均衡、校验、安全模式（P0 必划）

- 教材定位：教材印刷页141—142；PDF第154—155页；教材7.1.2 HDFS
- 教材上怎么划：
  - 圈出默认思路：多副本（教材示例三份）、跨节点/机架放置。
  - 依次给四项加编号：心跳检测、Balance均衡、CRC32校验、安全模式。
  - 划安全模式限制：不允许修改和删除；目的为启动时检查数据块有效性。
- 一句话记忆：副本保安全，心跳查健康，Balance调利用率，CRC32查错误，安全模式做启动检查。
- 易错提醒：Balance解决磁盘利用率不均，不是数据备份本身。

### 2-09 HBase定义及与关系数据库的区别（P0 必划）

- 教材定位：教材印刷页149；PDF第162页；教材7.1.4 HBase
- 教材上怎么划：
  - 划HBase定义中的五个词：高可靠、高性能、面向列、可伸缩、分布式。
  - 比较题只划五项：数据类型、数据操作、存储模式、索引、数据维护。
  - 补划横向扩展：关系数据库难横向扩展，HBase可增减集群硬件伸缩。
- 一句话记忆：HBase适合海量、稀疏、非结构化/半结构化数据，不擅长复杂多表连接。
- 易错提醒：HBase不是传统关系数据库，也不是HDFS的替代文件系统。

### 2-10 HBase数据模型（P0 必划）

- 教材定位：教材印刷页149—150；PDF第162—163页；教材7.1.4 HBase
- 教材上怎么划：
  - 在模型索引句中圈出：行键、列族、列限定符、时间戳。
  - 划“行+列族+列限定符确定一个单元格”。
  - 划单元格数据特征：无数据类型、字节数组、多个版本、用时间戳索引。
- 一句话记忆：定位一个版本常写作：row key + column family:qualifier + timestamp。
- 易错提醒：列族需要预先定义；列限定符可以不预定义。

### 2-11 HBase体系结构与三个核心角色（P0 必划）

- 教材定位：教材印刷页151；PDF第164页；教材7.1.4 HBase
- 教材上怎么划：
  - 框出三部分：HBaseMaster、HRegionServer、HBaseClient。
  - Master：管理集群/Region；RegionServer：处理读写、回写、压缩、分裂；Client：定位RegionServer。
  - 圈出ZooKeeper的选主作用以及Master故障后的重新选举。
- 一句话记忆：Master管调度，RegionServer干读写，Client做寻址，ZooKeeper保选主。
- 易错提醒：数据最终持久化在HDFS；ZooKeeper不是数据存储节点。

### 2-12 Hive定义、数据存储与四种数据模型（P0 必划）

- 教材定位：教材印刷页152—153；PDF第165—166页；教材7.1.5 Hive
- 教材上怎么划：
  - 划Hive定义：建立在Hadoop上的数据仓库基础架构，用于提取、转换、加载、查询和分析。
  - 划“所有数据都存储在HDFS中”。
  - 圈出四种数据模型：内部表、外部表、分区、桶。
- 一句话记忆：Hive提供HQL和仓库抽象，底层数据仍在HDFS。
- 易错提醒：删除内部表通常删元数据和数据；删除外部表只删元数据链接，不删原数据。

### 2-13 Hive架构与查询执行（P0 必划）

- 教材定位：教材印刷页154—155；PDF第167—168页；教材7.1.5 Hive
- 教材上怎么划：
  - 框出架构四部分：用户接口、元数据存储、Thrift服务器、驱动器。
  - 划元数据位置：MySQL、Derby等关系数据库。
  - 划执行链：HQL → 编译/优化/查询计划 → HDFS → MapReduce执行。
- 一句话记忆：Hive把类SQL的HQL翻译成Hadoop任务，不是低延迟事务数据库。
- 易错提醒：元数据存在RDBMS；业务数据存在HDFS，两者位置不要写反。

## 第3章 系统日志数据采集

### 3-01 Flume定义、Event与Agent三组件（P0 必划）

- 教材定位：教材印刷页38—39；PDF第51—52页；教材3.3 Flume数据采集
- 教材上怎么划：
  - 划Flume定义：分布式日志收集系统，把各服务器数据送往HDFS等目的地。
  - 划Event定义：Flume内部传输的最基本单元，由可选Header和字节数组Payload组成。
  - 给公式式记忆框：Agent = Source + Channel + Sink。
- 一句话记忆：Source接，Channel缓冲，Sink发；Event是流动的数据单元。
- 易错提醒：Agent不是单一Source；它是三个组件组成的运行单元。

### 3-02 Flume运行机制与可靠性（P0 必划）

- 教材定位：教材印刷页39；PDF第52页；教材3.3 Flume数据采集
- 教材上怎么划：
  - 按箭头划：Source接收 → Channel暂存 → Sink发往目的地。
  - 给“Sink成功发送后，Channel才删除临时数据”加双下划线，这是可靠性来源。
  - 圈出多级Agent、扇入fan-in、扇出fan-out。
- 一句话记忆：先落Channel、成功后删除，避免发送失败时数据直接丢失。
- 易错提醒：fan-in是多个输入汇入；fan-out是输出到多个目的地。

### 3-03 Scribe流程、容错定位与Store类型（P0 必划）

- 教材定位：教材印刷页40；PDF第53页；教材3.4 Scribe数据采集
- 教材上怎么划：
  - 划Scribe作用：日志分布式收集、统一处理，方案可扩展且高容错。
  - 划流程：ScribeAgent/Thrift Client → Category+Message → 共享队列 → 按Category送不同Store。
  - 圈Store类型：file、buffer、network、bucket、null、thriftfile、multi。
- 一句话记忆：类别负责分流，Message是内容，队列负责缓冲，Store决定去向。
- 易错提醒：PPT补充的故障转储细节以《补充复习内容》第3章为准。

## 第5章 互联网数据采集

### 5-01 网络爬虫定义、组成与基本循环（P0 必划）

- 教材定位：教材印刷页66；PDF第79页；5.1.1 网络爬虫的概念
- 教材上怎么划：
  - 划定义：按一定规则自动抓取万维网信息的程序或脚本。
  - 圈三个部分：数据采集、处理、存储。
  - 在基本循环旁写：种子URL → 下载 → 解析/提取新URL → 入队 → 重复 → 清洗存储。
- 一句话记忆：URL队列和抓取策略共同决定接下来抓哪个页面。
- 易错提醒：爬虫不是只下载HTML，还包含解析、清洗、存储等环节。

### 5-02 抓取策略：定义、深度优先与广度优先（P0 必划）

- 教材定位：教材印刷页67；PDF第80页；5.1.2 网络爬虫的抓取策略

  - 划策略定义：决定URL在待抓取队列中的排列顺序。
  - 框出常见策略名称；细节至少掌握深度优先和广度优先。
  - 在两种顺序旁标：深度优先一路向下再回溯；广度优先逐层展开。
- 一句话记忆：DFS适合垂直/站内深挖；BFS覆盖均匀但属于盲目搜索。
- 易错提醒：PageRank、OPIC等策略细节优先查《补充复习内容》第5章。

### 5-04 深层网络爬虫与分布式网络爬虫（P0 必划）

## 第6章 数据预处理技术

### 6-01 属性类型与中心趋势（P0 必划）

- 教材定位：教材印刷页104—106；PDF第117—119页；6.1.1—6.1.2
- 教材上怎么划：
  - 圈四类属性：标称、二元、序数、数值；数值属性再分离散/连续。
  - 二元属性旁标对称/非对称；序数属性强调‘有序但相邻差未知’。
  - 中心趋势圈均值、中位数、众数、中列数；倾斜数据优先考虑中位数。
- 一句话记忆：标称无序；序数有序；数值可做算术；非对称二元中1更重要。
- 易错提醒：给类别编码0/1不代表它自动变成可做算术运算的数值属性。

### 6-02 方差与标准差（P0 必划/会算）

- 教材定位：教材印刷页108；PDF第121页；6.1.2 数据的统计描述
- 教材上怎么划：
  - 划方差、标准差的含义：衡量数据分布的散布程度。
  - 框出式(6-5)方差公式，并在旁写：标准差 = 方差的平方根。
  - 写结论：低标准差更集中，高标准差更分散；全相同时标准差为0。
- 一句话记忆：先求均值，再求离均差平方的平均，最后开方得到标准差。
- 易错提醒：若题目明确要求样本方差，分母可能是n-1；教材此处按其给定公式作答。

### 6-03 标称属性、二元属性与Jaccard（P0 必划/会算）

- 教材定位：教材印刷页110—111；PDF第123—124页；6.1.3 相似性与相异性
- 教材上怎么划：
  - 标称属性框公式：d=(p-m)/p，sim=m/p。
  - 二元列联表标清q、r、s、t；对称二元把四项都计入。
  - 非对称二元忽略t；框Jaccard：sim=q/(q+r+s)，d=(r+s)/(q+r+s)。
- 一句话记忆：Jaccard只关心至少一个为1的位置，不把共同为0当相似证据。
- 易错提醒：教材OCR可能把字母识别错；计算时以q=共同1、r/s=不匹配、t=共同0为准。

### 6-04 欧氏、曼哈顿、闵可夫斯基距离与余弦相似度（P0 必划/会算）

- 教材定位：教材印刷页111—113；PDF第124—126页；6.1.3 相似性与相异性
- 教材上怎么划：
  - 框欧氏距离式(6-13)、曼哈顿距离式(6-14)、闵可夫斯基距离式(6-15)。
  - 在闵可夫斯基旁写：h=1得到曼哈顿；h=2得到欧氏。
  - 框余弦相似度：X·Y/(||X||||Y||)；越接近1越相似，0表示正交。
- 一句话记忆：距离越小越相似；余弦越大越相似。不要把方向弄反。
- 易错提醒：余弦比较方向，不直接反映向量长度差异；计算分母是两个模长的乘积。

### 6-05 数据预处理任务与六个质量维度（P0 必划）

### 6-06 数据清洗与缺失值处理（P0 必划）

- 教材定位：教材印刷页115—116；PDF第128—129页；6.3—6.3.1
- 教材上怎么划：
  - 划清洗目的：填补缺失、平滑噪声、识别/删除离群点、纠正不一致、去重。
  - 六种缺失值处理法依次编号：忽略、人工、全局常量、中心度量、同类中心度量、最可能值。
  - 在均值/中位数法旁写：对称分布用均值，倾斜分布用中位数。
- 一句话记忆：方法选择取决于缺失比例、数据量、分布与业务含义。
- 易错提醒：缺失不一定是错误；例如‘无驾驶证’对应字段为空可能是合理空值。

### 6-07 分箱光滑：箱均值、箱中位数、箱边界（P0 必划/会算）

- 教材定位：教材印刷页116；PDF第129页；6.3.2 光滑噪声数据处理
- 教材上怎么划：
  - 划分箱定义：考察近邻值，把有序数据分到桶/箱中进行局部光滑。
  - 框图6-5的原始序列、等频分箱、箱均值与箱边界结果。
  - 写算法：先排序 → 分箱 → 用均值/中位数/最近边界替换。
- 一句话记忆：边界法把每个值替换成同箱中距离它最近的最小或最大边界。
- 易错提醒：等频是每箱元素个数相近；等宽是每箱数值区间宽度相同。

### 6-08 数据集成、相关系数与协方差（P0 必划/会算）

### 6-09 数据归约：维归约、数量归约、数据压缩（P0 必划）

- 教材定位：教材印刷页122；PDF第135页；6.5 数据归约
- 教材上怎么划：
  - 划归约定义：数据集变小但近似保持完整性，挖掘结果近乎相同。
  - 圈三种策略：维归约、数量归约、数据压缩。
  - 分别写关键词：删/投影属性；用模型/抽样/聚类等替代；无损/有损压缩。
- 一句话记忆：维归约减列，数量归约减行或用小表示，压缩改编码表示。
- 易错提醒：归约目标不是简单丢数据，而是在尽量保持分析结果的前提下降低规模。

### 6-10 数据变换的六种常用策略（P0 必划）

- 教材定位：教材印刷页128；PDF第141页；6.6 数据变换
- 教材上怎么划：
  - 给六项编号：光滑、聚集、属性构造、规范化、离散化、数据泛化。
  - 规范化旁写：缩放到小区间；离散化旁写：连续值换区间/概念标签。
  - 泛化旁写：低层概念换高层概念，如街道→城市→国家。
- 一句话记忆：光滑去噪，聚集汇总，构造新特征，规范化缩放，离散化分段，泛化升层。
- 易错提醒：这些技术可能交叉：分箱既可清洗，也可离散化；聚集也可用于归约。

### 6-11 三种规范化方法（P0 必划/会算）

- 教材定位：教材印刷页129—130；PDF第142—143页；6.6.1 通过规范化变换数据
- 教材上怎么划：
  - 框最小—最大规范化式(6-24)，注意映射区间[new_min,new_max]。
  - 框z分数规范化式(6-25)：(x-均值)/标准差；极值未知或有孤立点时更合适。
  - 框小数定标式(6-28)：x'=x/10^j，j使最大绝对值缩到1以内。
- 一句话记忆：Min-Max依赖极值；Z-score依赖均值与标准差；Decimal Scaling移动小数点。
- 易错提醒：Min-Max映射到[0,1]时才可简写为(x-min)/(max-min)；其他新区间要乘区间长度并加new_min。

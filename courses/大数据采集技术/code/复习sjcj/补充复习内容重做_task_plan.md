## P0 Requirements
- 第1章：补三个机构定义；扩写1.3；解释第三/第四范式差异；1.5、1.6降级为不考提示。

- 第3章：补Chukwa与Kafka。
- 第5章：补基于网络拓扑/网页内容的两类算法；补OPIC、反向链接、局部PageRank及作弊/广告链接局限。

## Decisions Made
- 新版定位为“独立可读的补充讲义”，不再只是PPT提纲。
- 与教材重复的内容只做必要承接，并明确跳转到 `教材重点.pdf`；补充讲义重点解释教材未展开或PPT口径不同的内容。
- 1.5、1.6保留一页“低优先级/不考”边界，不投入大篇幅。
- 最终仅覆盖生成物 `补充复习内容.pdf` 和同步Markdown；教材、PPT、新版教材重点及其他复习PDF保持不变。

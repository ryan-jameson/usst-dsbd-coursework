# 上海理工大学 · 数据科学与大数据技术课程资料

**上海理工大学（经管实验班—数据科学与大数据技术专业）**

本仓库整理自本人在上海理工大学经管实验班、数据科学与大数据技术专业学习期间的平时作业、实验代码、课程报告、PPT 文字内容和学习笔记，希望为本校相关专业，以及数据科学、计算机与经管交叉方向的同学提供参考。整理与维护：[ryan-jameson](https://github.com/ryan-jameson)。

这是个人课程资料整理。课程要求、软件环境与考核方式以当期教学安排为准。

## 仓库内容

- 3,433 个经过整理的代码与笔记文件。
- 486 份去重后的文档文字版，覆盖报告、课件和阅读材料。
- Word/PPT 文字内容同时提供 Markdown 和可编辑的 DOCX/PPTX 文字版；PDF 提供抽取后的 Markdown。
- 按课程设置目录、材料索引、来源说明与隐私处理说明。

## 从哪里开始

1. 在下面的课程索引中选择课程，阅读该课程的内容概览。
2. `materials/` 存放脱敏文字版，`code/` 保留代码和笔记的相对组织结构。
3. 先读项目原有说明与依赖文件，再调整本地路径和运行配置。凭据占位符需要在本地自行配置。
4. 本次核验包括文件结构、Notebook 输出清理和部分代码语法检查；尚未逐一复现实验或验证所有依赖。

## 公开版本的范围

姓名、学号、联系方式、个人目录信息和识别到的凭据已做替换；Notebook 历史输出、附件和运行元数据已清除。文档通过重新生成文字版移除原图片、批注及嵌入对象。

安装程序、运行环境、缓存、原始医疗数据、模型权重、视频/图片原件、私人行政财务记录、未能可靠抽取的扫描材料与原始压缩包不在公开仓库中。ZIP/RAR 内可处理的代码和文字文档已提取、去重后归入相应课程。

因此，公开仓库是学习资料的脱敏整理版，不是原目录的逐文件镜像。完整原件另有本地备份；删除原目录前应保留并验证那份备份。详见 [内容覆盖说明](COVERAGE.md)。
